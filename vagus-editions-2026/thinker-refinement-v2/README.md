# Vagus 思想者 · 造型与对位 v2

这是独立的第二轮灰模审阅页，不是最终作品集。手仍是原创程序建模的简化形体；已收窄掌部、改连续弧线卷指、平滑食指根部权重，并把球形袖口换成有开口/内外壁的布褶。手机保持固定，默认不露屏，只有食指5秒内约3次短上划、停2秒后循环。未修改旧站或第一版灰模。

## 打开
已有Node.js环境中双击start.cmd，在Google Chrome访问 http://127.0.0.1:4181 。无需登录、npm安装、联网或付费。只播放不需要Blender；可编辑源文件在assets/thinker-gray.blend，网页模型为assets/thinker-gray.glb。

默认为局部灰模，可切近景和“原画对位 · 灰模”；接触侧仅用于审核指腹，不是正式网站镜头。关键帧用于审阅，正常播放才是实时动作。暂停、离屏、后台和系统减少动态会停止自动推进。加载失败保留同构图封面；原画补图失败仅关闭对位入口，灰模继续可用。

## 原画对位的边界
采用1672×941原图的手机四角与腕部5点作正交镜头拟合，RMS约2.74原图像素，各点误差小于6像素；新GLB以真实相机投影显示，不是平面手部拉伸。局部清理用已有R3补图，脸和其他区域继续显示原图；原画衣袖作为遮挡层盖住前臂，校准模式隐藏三维书/桌面/灰袖口，保留原画供尺度与接续判断。

这只证明给定视角的标定，不证明整只手轮廓已与原画一致、接触阴影已融合、书页全场深度已标定或支持滚动拉远。灰模里的完整书/桌面/袖口另行检查，最终融合前仍需雕形和表面材质工作。原画本身只是原有完整图，不冒称已完成房间分层或实时3D人物。

## 验证
运行 node --test tests/*.test.mjs tests/*.test.cjs 。23项实际检查包括真实GLB单连通手面、71时刻蒙皮顶点接触、固定腕面、28mm上划、5+2停顿、手机85处底面不穿页且有承托区域、厚壁开口袖口、三画幅标定和背壳可见性、加载/HTTP保护。资产检测不能代替艺术接受。

Google Chrome正常连接入口已打开预览；可复现检查另用D盘隔离Chrome。evidence中保留关键帧、真实7.8秒录像、对位截图及结果。工具脚本browser-*.cjs使用本机现有Playwright路径，重建需已有Blender与NumPy；网页和Node资产测试不依赖这些工具路径。

掌部、虎口、指甲和袖口仍待视觉精修；未完成最终石质绘画纹理、橙红手机材质、房间深度、F2滚动或其他章节。未验收真机、其他浏览器、辅助技术和长期FPS。不能把这一轮称为Shopify同等画质。
