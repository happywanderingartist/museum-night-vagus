# 效果重建配方与可执行接入

3.0 提供“原理可执行、视觉待资产”的参考。参数为原创重建初值，不是原站测量；能生成相近运动语法，不保证未经制备的素材也同样好看。先读 asset-contract.md，保留 Vagus 用户约束。旧 motion-contract.md 的轻淡出不是本模式默认方案。

## 先填效果矩阵

每行填目标、参考证据、所需资产、实现方式、0/25/50/75/100% 画面、实测状态和缺口。用户指定的核心效果不能都降级成 fade。

| 目标 | 选择的机制 | 关键限制 |
|---|---|---|
| 近景到较完整取景 | 同坐标图层不同缩放与位移，或真实网格相机 | 单图不能找回画幅外人物；不要不经说明把它叫相机绕行 |
| 巨标题 → 说明 | 独立时间段退出／出现，底图仍连续 | 两套文字过渡不得同等清晰叠读；入口不被动画阻挡 |
| 图像 → 实底阅读 | 同一阅读底色的边界揭示接正常正文 | 终态有完整阅读区，不把正文放进只停留一瞬的镜头 |
| 章节的方向感 | 可逆进度＋稳定导航／URL | 直接进入、反向和返回都应同步当前状态 |
| 编辑式留白与局部裁切 | 短幅图层差速，主标题保持正常阅读 | Contra 路线不强制巨字消失或纸边 |
| 页级入场、悬停、局部循环 | 独立 time／hover／idle 通道，明确复播规则 | 与滚动通道不互相重置；素材／具体机制未验证时标待制备／待测 |

最后一行在本包中是合同要求，不含原站完整预加载或 Rive 实现；有逐项需要时再为该效果制备资源，不能宣称当前模板已覆盖全站。

## A：沉浸式章节的分段进度

将章节的可滚动长度归一为 p：clamp((scrollTop - sectionTop)/(sectionHeight - viewportHeight),0,1)。参考模板 section=200svh，sticky stage=100svh：总新增推进约一视口，p=1 释放，后续正文继续普通文档流。它服务三段不同叙事，不是多屏空白；用户快速跳过不被拦截。内容放大后容纳不下时应减少驻留或转静态，不强行挤进舞台。

| p 区间 | 主体／背景 | 字图与材料 | 稳定状态 |
|---|---|---|---|
| 0–.24 | 主体由 1.24 向 1 拉开，背景由 1.10 向 1，差速而非整图同动 | 巨标题从 .10 开始退出，.30 结束 | 开场已有语义标题与可用链接 |
| .24–.55 | 拉开至更完整的原素材取景；主体位移16→-8px、背景0→-12px | 说明在 .24–.40 进入；图像仍连续 | .40–.62 为说明主导状态 |
| .48–1 | 图像保持，不靠全屏淡黑掩盖交接 | 阅读表面从底部升起，材质边缘可替换；说明 .62–.74 退出 | p=1 阅读底覆盖画面并连接真实正文 |

模板用分段线性映射随滚动更新，不增加弹簧滞后。它是 2.5D 摄影视觉近似；相机轨道、骨骼和着色器不是这几行 DOM 代码自动获得的功能。纯装饰背景和边界 pointer-events:none，入口在安全前景层且语义链接可用。

说明是上方独立前景层，不是被阅读边界剪切的文字；模板在边界到达说明安全区前结束其显示。若实际中文排版更高，应改说明宽度／位置或提前退出，不让浅字叠到浅底。边界终点上移额外6%消除不规则顶缘漏图。链接区域先被阅读底覆盖，navTone 因而提前换深色字；正式全局目录应按自身背后区域计算，不照抄此阈值。

终点不能是一整屏无内容的浅色。夹具的 reading-intro 展示“阅读阶段”测试文字，正式接入替换为真实作品标题／已有短导语，不能原样保留或凭空新增个人经历。完整正文仍在正常文档流；真实标题只保留一套语义，不用复制假正文填满舞台。阅读入口不放在 pointer-events:none 的边界层，仍用可聚焦前景导航／正文链接。用户不允许额外说明时，只用已有真实标题，调整材料推进与正文相接的位置，而不是塞新文案。

夹具边界层整体 aria-hidden，其短标题只是视觉预告；正式接入若采用视觉副本，从真实内容生成并保持 aria-hidden／无可聚焦控件，真实标题和正文必须始终存在于后续正常文档流，静态后备不能丢失。也可不用副本，改为让真实正文更早进入视口；无论哪种方案都不能留下空白镜头作为终点。

## B：编辑式页面

普通文档流不强制驻留。背景位移0→-8px，主体1.04→1、0→-20px，标题／说明不按时间消失；下一内容自然进入。该微差速仅为初值。若目标是独立拼贴图像，按每片真实边界与裁切分别定路径，不能把整页套同一个幅度后声称复现了原站。图像与正文的编排仍须先静态成立。

3.1.1 的 B 进度从章节顶部到达视口顶部开始，到章节底部到达视口顶部结束：p=clamp((scrollTop-sectionTop)/sectionHeight,0,1)。不使用 A 的 sectionHeight-viewportHeight 分母，避免短首屏永远停在0；进入视口前保持起帧，退出完成终帧。不要为了微差速人为延长首屏。页面滚不到完整终帧时，以实际可达范围检查，不能用采样按钮代替原生滚动。

两种路线的背景与主体均使用全幅 `.vagus-art`，主体偏右由透明素材的母版坐标决定，不再把整个美术容器裁为右55%。左侧明暗色层属于背景，不能留给单一底色替代。默认各图层共享24 CSS像素的外扩画布与相同object-fit／object-position；这会轻微放大母版，文字安全区须在外扩后的实际裁切上核对。同一画布所有图层一起外扩，不单独扩大背景破坏静态对位；素材必须含真实边缘内容，透明空白不是背景余量。默认24px覆盖包内最大20px位移；修改变换后按全进度、实际尺寸重新计算，不把24px推广为任何动画的通用值。

## 包内可执行资源

- [motion-runtime.mjs](../assets/motion-runtime.mjs)：纯时间线 sampleScene、原生滚动 mountScene、立即同步与 destroy 清理。
- [motion.css](../assets/motion.css)：命名空间样式、sticky 章节、图层与材料揭示、正常文档流后备。
- [scene-fixture.html](../assets/scene-fixture.html)：中性几何测试夹具，可选 A/B、采样进度与原生滚动。不是正式 Vagus 风格范例。
- [test-runtime.mjs](../scripts/test-runtime.mjs)：无外部依赖，运行 node scripts/test-runtime.mjs 或 node --test scripts/test-runtime.mjs。

把 assets/ 三文件置于项目开发服务器同目录再打开夹具。不要直接双击 file:// 运行 ES 模块后把 CORS 失败误当动画错误。测试夹具不使用参考画作，无第三方运行时依赖；制作时迁移机制而非照搬几何外观。对已有 React／Motion 项目应复用已有调度、组件生命周期和 token，不额外装一套滚动库。

没有项目服务器时，可在技能目录显式运行 node scripts/serve-fixture.cjs，打开其打印的本机地址；此脚本仅服务三个夹具文件，绑定127.0.0.1随机端口，Ctrl+C关闭。安装 Skill 不自动启动服务。受控环境若隔离进程网络，应说明限制，不能为了验证而开放公网端口。

基本接入：

```js
import { mountScene } from './motion-runtime.mjs';
const controller = mountScene(document.querySelector('[data-scroll-scene]'));
// 路由卸载时：
// controller.destroy();
```

沿用夹具标记：data-profile 为 immersive 或 editorial；data-layer 为 background、subject、title、description、reading；vagus-stage 内分层，真实作品放在舞台后正常文档流。替换几何层为已核验无字素材，设置共享画布与裁切、字体与真实内容。背景／主体素材缺一时先别宣称独立差速已完成。

preview(p) 仅供夹具确定性采样，不能接管真实用户滚动；重新滚动会恢复当前原生进度。destroy 清理监听器、observer、帧请求并恢复本模块设置的样式。不能把 demo 采样截图当原生滚动、参考站或正式页面已验收证据。

## 必须单独实现的网页系统

导航从中心到侧栏不是“放个固定左栏”就等价：用同一语义目录，或让视觉副本 aria-hidden／不可聚焦；定义起终矩形，按实际字体与换行重算。保留一个可操作目标，不让视觉副本成为第二套 Tab 顺序。对比色跟阅读底状态同步，hash／后退独立于动画。模板只输出 navTone，站点全局导航要显式消费它，不能宣称自动接好全站目录。

预加载只等待当前视口关键资产，优先同构图 poster，不阻塞导航和真实正文。需要“加载动画衔接角色动作”时须有连续端帧与相同资产，不能随机开场动画播完后硬切另一幅画。取消／跳过／回访要直接终态。局部 idle 离屏、页面隐藏或减少动态时暂停；hover 只在 fine pointer 开启，触屏和键盘仍完整可用。

## 图像相似度验收不是运行时单元测试

先按相同画幅比较三至五个关键进度：主体占画幅、关键手势位置、标题与主体关系、前后层差速、边界推进和正文稳定。记录参考观察、自己的重建与仍不同处；不复制受保护角色或布局来追求像素一致。几何夹具通过只证明机制能跑，不证明美术达到参考水准。

再实测原生滚动、停止、反向、快跳、hash、后退、字体就绪／图片加载／resize、路由卸载、窄屏、减少动态与失败后备。示例1024px只是夹具值；迁移时按内容安全区同时修改 runtime 常量与两处 CSS media query，不提供只改一侧的断点选项。最后才给“功能通过／视觉待审／用户接受”三个独立结论。
