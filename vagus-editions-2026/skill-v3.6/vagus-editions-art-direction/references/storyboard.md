# 分镜与图层合同

本文是轻量编辑页的兼容方案。用户要求接近参考的取景拉开、差速、字图交接与材料揭示时，使用 effect-recipes.md 的3.0时间线，不以本表短淡化覆盖该目标。

比例指主图占宽；可分别用于不同章节，不强制同一角色逐次缩小。本表是 Vagus 提案，不是原站逐帧复刻。

| 状态 | 布局／阅读 | 触发／结束／反向 |
|---|---|---|
| 开场 | B 优先：右侧大思想者，左侧标题、自然段简介与竖排入口；统一安静底面 | 首帧可读，不等预加载才能操作；回顶同构图 |
| 进作品 | 伴图可半屏，也可退出，让真实作品成主角 | 短淡化／裁切，停滚稳定、反向恢复；不用强制缩小仪式 |
| 阅读 | 依内容用三分之一伴图或无伴图，正文足够宽 | 不按计时隐藏，键盘可用；无内容只交提案，不造案例 |
| 换章节 | 主色、场景、占幅可变，导航逻辑不变 | 可跳转；无动态时文档流；失败时全部静态可达 |

定时过渡可试 180–360ms，滚动过渡可试 0.25–0.6 视口：只是项目起点，非原站实测值；真实页面测试后决定，不硬凑参数。

图层：底面／环境 → 主体与有接触关系的电脑 → 可选前景遮挡 → 可编辑标题／简介／导航／入口 → 焦点。人物与电脑可先是一体素材保证接触，不冒充完整可编辑三维资产。

## 素材提示词

先指定路线、动作、占幅、取景、光线、媒介、边界处理和 UI 安静区，再写禁项。不要继续“中性棚拍石像＋任意背景”。原素材留关键部位与裁切余量，合成取景另定。B 可用真透明主体或融合底面图；A 统一制作环境与主体，不随机独立生成后拼接。无标题、导航、按钮、卡片、气泡、水印、品牌和额外设备。未授权生成时只交提示词。
