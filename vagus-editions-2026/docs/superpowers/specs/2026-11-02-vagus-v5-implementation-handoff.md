# Vagus v5 后续制作交接

2026-11-02。本轮是设计交付；下列是设计确认后的制作顺序，不代表网站已经开工。

先读 [审阅入口](2026-11-02-vagus-v5-design-contract.md)、[DESIGN](2026-11-02-vagus-v5-DESIGN.md)、[主方案](2026-11-01-vagus-continuous-gallery-v5.md) 与 [素材合同](2026-11-01-vagus-continuous-gallery-v5-assets.md)。原始网页和图像位于 `vagus-editions-2026/site-v4/`。本次 SVG 的 UI 是近似版位，正式端态以现有页面的同视口截图为准。

1. 锁定原首页与 AI 对照，核验高分辨率母版、来源与候选分层；不要先改原网页。原图不近推也不重绘人物。若引入局部分层运动，先证明去人物底图、外扩、alpha 与接触总组成立。
2. 设计确认后，第一份制作工件应是一段标明灰模的可逆短验证：p=.06—.38 展开绘画轮廓开口，p=.26—.88 在新展廊内前行，到达端用近景墙缘遮住接缝后接回原 AI。开口是视觉语法；原画不充当要穿过的三维墙。只验证这一段，不扩全站、不重做人物。
3. 画面必须证明同一目的空间从入口可见、地面方向连续、近景从周边经过、原画端态匹配，并能在中途停住和反向。不得用五帧截图、黑幕或整图放大宣称这项通过。
4. 灰模通过后制备有原画笔触、透视与光线的连续环境。保留原浅青与深绿、暖木的材料关系；K2 平涂色块不是最终纹理。按真实最大投影和 DPR 核算原生细节、外扩与加载预算。
5. 网站实施前按项目规则审阅成熟开源方案并记录优势/局限；随后再细化控制权表和最小实现。建议 Three.js 仅负责新环境相机/厚度/遮挡，HTML 保留原文与链接；一个进度源、一个属性写入者。旧控制器解除对应属性后才接管。

文字落点：AI 左轴 6vw、标题及正文沿原 CSS；标题 .68—.76、简介 .74—.84、入口组 .82—.88 建立，实际遮挡优先。镜头 .88 后停止，正文正常流动。快滚、邀请、AI 导航、直接链接可跳过，反向与文章后退恢复各自来源位置。窄屏、减少动态和资源失败优先完整静态流，不留下空舞台占位。

首轮审阅只判五项：原设计保护、连续空间、人物接触及画质、阅读可达、单一控制与失败恢复。现有文章/产品证据缺口按事实保留。功能与视觉分别记录，用户接受前不把灰模当正式美术成品。
