# Vagus 两幕衔接修订

2026-11-09。依据用户对当前试制“衔接有点奇怪”的反馈，修订独立预览。此次把长展廊压缩成一次短门槛，是制作方为审阅提出的调整，尚未得到用户视觉确认。原 v5 文件保留历史，其中开口和中间长展廊的执行定义在本试制中被本稿取代。

## 画面原因与取舍

Chrome 画面显示，原椭圆开口切过人物、电脑和桌面，开口后进入空旷几何走廊；抵达 AI 又采用中央向两侧的不同裁切方向。两幕间同时切换媒介、透视目标和转场方式，因而显得分段拼接。只调缓动无法解决这种关系。

本次采取整幅首页沿滚动方向向上退出，AI 原画提前在后面建立的方式，保留竖向阅读方向。新几何只承担左右近景厚边与前进遮挡，取消完整长走廊和闭合四边框。两幅原图不增加观看角度，猫杯桌及手机古书的接触关系随各自整幅画面保留。画面推进感由门槛的相机透视承担，原 AI 画面始终使用终态取景。这种组合仍是两幅作品的舞台交接，没有证明原画是可穿行的连续三维房间。

原先的开洞进入会继续切过人物，因此撤去；补齐完整连续展廊需要额外环境母版和接缝资产，本轮仅用现有资产测试较短衔接。后续若用户偏好明显的长距离漫步，仍须先完成连续环境美术，不能靠重复增加几何门廊得到。

## 五阶段与运动

| 阶段 | 画面和职责 |
| --- | --- |
| 首页停留 p=0 | 原首页 HTML、图像、位置与链接完整可用 |
| 开始交接 p=.04—.30 | 首页作为整幅平面向上移动，HTML 文字按 .02—.17 让位；AI 原画已在后层，两侧近景厚边形成遮挡 |
| 途中 p=.30—.50 | 首页继续退出；相机从 .12 起单调前进，侧边透视展开。没有独立空走廊和全屏空白 |
| 抵达 p=.50—.76 | 首页完全离开，门槛逐步越过视野；标题 .50—.64、简介 .55—.70、入口 .64—.76 接力，文字不随相机缩放 |
| 阅读 p≥.76 | 相机停稳，门槛退出，原 AI 构图和链接保持可读；继续下滚进入正常文档流，反滚按原进度恢复 |

原生行程仍为 1.2H，滚动直接映射 p。首页位移使用 smootherstep(.04,.50)，相机使用 smootherstep(.12,.76)，只受实际滚动位置控制。停止不漂移，反向不重播，直接 #ai 跳到终态并聚焦。原减少动态、关闭动态、矮/窄窗口与渲染失败的静态后备继续保留。
