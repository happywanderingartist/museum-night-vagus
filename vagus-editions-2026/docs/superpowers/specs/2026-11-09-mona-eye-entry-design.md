# 蒙娜丽莎眼部入口 · 五帧构图 v1

本轮完成静态构图与素材核算。五帧采用原首页实景、原画裁切和现有空间目录实景合成。连续镜头、正式眼部素材和章节展开仍待制作。保留蒙娜丽莎工作室封面，通过同一只眼睛进入已确认的空间目录，随后从选中作品展开真实章节。

## 审阅文件

总览为 `2026-11-09-mona-eye-storyboard.svg`，画布 1920×1160。独立帧为 `2026-11-09-mona-eye-k0.svg` 至 `k4.svg`，每帧 1440×810。JPG 是浏览器导出的 688×416 低分辨率预览，细看构图与说明请打开 SVG。源实景捕获的网页视口为 1440×810，截图工具实际输出 1425×802，已按约 16∶9 排入画框。

## 镜头节奏与衔接提案

滚轮向下推进，向上可反向回退。进度 p 从 0 到 1 表示入口镜头，暂按约一个视口高度的滚动距离试制，不设强制等待。点击原有进入邀请时自动完成同一条路径，起始试制时长约 1.4–1.8 秒。以下比例为待验证参数，静态分镜无法证明运动连贯。

| 区间 | 镜头与界面行为 | 自动播放时长量级 |
|---|---|---|
| K0 → K1，p 0–.28 | 温和加速接近面部，缩放与位移同时发生。标题先淡出，眼睛平滑移向光学中心。 | 约 400–500 ms |
| K1 → K2，p .28–.57 | 沿原观看方向继续靠近。使用对数尺度插值控制放大速度，避免大部分时间停留在全景，最后突然冲向眼睛。 | 约 400–500 ms |
| K2 → K3，p .57–.80 | 在镜片与暗瞳孔占据画面时完成素材桥接，目录提前就位。遮罩边缘持续扩大，镜头保持前进。 | 约 300–400 ms |
| K3 → K4，p .80–1 | 瞳孔边缘离开视野，空间尺度延续并逐渐减速。稳定后开放目录拖动，HTML 信息随到达出现。 | 约 300–400 ms |

整段共享一次加速、一次减速，中间关键帧仅用于审阅，不逐帧停顿。滚动驱动使用一条可反向的进度，不给每段叠加独立缓动。自动进入可用整体 ease-in-out，移动速度需通过连续样片再调。素材加载完毕后才启动进入，等待期间保留完整首页及可用的直达导航。

本轮选择正向推进路线，眼部锚点暂设源图坐标 (901,237)。该位置通过构图试排确定，正式眼部素材需再次校准真实瞳孔中心。

不能通过整张图无限放大解决眼部画质。正式素材应按最终最大片上尺寸核算，例如眼部桥接层若占满 1440×810 且目标 DPR 为 2，应提供至少覆盖 2880×1620 的有效细节，再留取景余量。增加文件尺寸不等于增加真实细节，补制后需在目标设备 100% 尺寸审阅。补制范围限定面部与眼部，原首页仍使用原画。

## 目录之后与返回

选择作品后，选中画面从球面转向正面，其他画作逐渐退开，选中画面放大到章节视觉区域。标题、真实作品简介和三条现有入口通过 HTML 排版出现。阅读到达后固定背景，正文使用普通纵向滚动，三条入口优先排为紧凑的纵向目录，最终名称和内容取自现有页面。

阅读页的“返回空间目录”恢复离开时的球面朝向、选中作品及键盘焦点。眼部穿越用于封面进入目录这一段。目录另设“返回封面”，反向完成同一条眼部路径。速览、简历和减少动态偏好均可直接进入稳定 HTML 页面。下一阶段才细化目录到章节的连续镜头，以上布局仍为设计提案。
