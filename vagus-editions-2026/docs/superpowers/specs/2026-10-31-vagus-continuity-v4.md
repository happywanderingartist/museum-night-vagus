# Vagus v4：画面、说明与阅读的连续交接

2026-11-01｜设计修订，未开发网站，未获连续效果验收。文件名沿用用户要求的2026-10-31前缀。用户本轮要求继续研究2／3／4并优化衔接与排版；这不等于批准重新设计原页面。本稿取代 v3 中相隔2单位、AI作为小矩形显露的参数，保留其原画保护、接触约束、素材审计和静态阅读要求。

先看[新版五帧与时序](2026-10-31-vagus-continuity-v4-frames.svg)，再看[阅读排版与字体示意](2026-10-31-vagus-continuity-v4-layout.svg)；[研究记录](../../../research/2026-11-01-scroll-continuity-234.md)保留来源与实测边界。两张 SVG 均为构图示意，不是运行网页、真实分层成品或连续效果证明。图中为突出画面与正文关系省略导航和原台词，正式端态继续沿用原页，不删除这些内容。

## 为什么要改

v3 的相机坐标连续，但首页近景与 AI 小画之间缺少内容关系；桌沿放大、小矩形周围空缺和过晚出现的文字，让接缝显得突出。v4 用一条语义接力辅助空间接力：首页的现代工作物件离开，AI 的手机与古书显露，原标题告诉访客进入哪个主题，原简介解释关注点，三入口最后留在稳定阅读面。说明动效首先是让人看懂这种关系，不额外增加解释卡片、指示箭头或新文案。

参考2支持按读者节奏安排图文与停顿；3支持连续叙事与定位；4支持互动场景和深入阅读分开组织。以上是迁移判断，来源详见研究记录。Chrome 原生窗口绑定失败，本轮未重新观看三站连续滚动，不将制作说明写成实测。

## 1. 空间和布局的修订

首页仍满幅开场。AI 环境从下方接管整个舞台宽度，不再在周围空白中展示一个有四边的缩小矩形；其人物、手机、古书及桌面保持原取景与接触关系。首页真实桌沿承担一次前景遮挡，经过上方后退出。两幅画仍有独立的光线和叙事，空间是虚拟展陈，不改画中建筑、不挖门洞、不走到人物侧背。

满幅环境需要独立干净底图、有效外扩与前景接触总组。当前仅确认完整原图；分镜暂将 AI 整图铺作环境与主体的构图代理，没有声称已实现独立层深。正式有分层时，AI 接触总组可在环境前产生有限距离感，环境必须补齐被原人物遮住和因新裁切露出的区域。合格素材到位前，效果只能称构图试验。

### 本版与 v3 的比较

| Before：v3 | After：v4设计提案 |
|---|---|
| 两页深度相隔2；中途 AI 约64%宽，矩形边界突出 | 深度间距0.60；中途接触组投影约86%宽，环境另以满幅底图承接；四边矩形不作为造型 |
| 首页最后露出的局部约3.215倍，过分依赖高分辨率补画 | 通过更大的纵向错位和更小的向前行程，让首页先离屏；几何代理最大可见放大约1.326倍 |
| 三条入口等到镜头完全结束才整体建立 | 标题先在原位置建立，原简介随后说明主题，三入口作为一组出现；进入阅读前已完整稳定 |
| 中间帧基本只有图像和导航 | 原标题提供持续的屏幕位置锚点，出现后保持静止；图像可以继续轻微收束 |
| 图面、空间参数独立交付，缺少文字时序对照 | 每帧同时写明画面、文字、可操作状态；用时序带解释先后与重叠 |

几何试制初值：W=2、H=1.125，首页中心 A=(0,0,0)，AI 接触组参考平面 B=(0,−1.35,−0.60)，固定垂直视角35°，d=H/(2tan17.5°)≈1.784。相机 C(p)=(0,−1.35q,d−0.60q)，q=6p⁵−15p⁴+10p³。x不变，俯仰、偏航、滚转都为0；两轴由同一q驱动，方向连续。终点距AI仍为d，参考平面的起终投影一致。

v4 相机不跨越首页 z=0 平面，而是在其前方下降后对准 AI；“经过桌沿”指其投影从上方离开视野，不宣称镜头穿过真实桌底或房间。纵深来自有限投影差、独立图层和遮挡，不要求物理穿越原画。取消 v3 的新增短展页侧面作为默认造型；只有后续灰模证明需要且有可见素材时才另审，避免叠加另一条硬边。

首页完全离屏的临界 q=H/(1.35+0.60tan17.5°)≈.731，最大可见放大M=d/(d−.60q)≈1.326；中途 q=.5，AI 接触组参考投影 d/(d+.30)≈.856。数字由本项目几何计算，不是参考站测量。背景满幅与主体投影分属不同层，不可将同一整图同时作为底图和重复人物叠两遍。

## 2. 五帧与说明动效

触发类型：R静态阅读、S滚动关联、C显式导航；不新增A自动人物动作。p只覆盖约0.9视口的交接，首页与阅读停留在前后，均不限时。快滚可直接跳到终态，不拦截滚轮。

| 帧／p | 画面与焦点 | 文字／入口状态 |
|---|---|---|
| K0／0 | 原首页完整构图；粉电脑、猫杯桌与手臂支撑完整 | 原字标与右侧理念、原台词、底部邀请和三入口照常可用 |
| K1／.30 | 视线下行并轻微进入纵深，首页仍占主要面积；AI 环境从底部接入 | 首页内容随原章节退出，不扭曲字形或把品牌缩成画中小字；导航按原显示规则工作 |
| K2／.50 | 首页桌沿位于上方近景；下方先露出 AI 的手机、古书和手势，延续“现代工具进入古典场景”的主题 | 此时不在远处画面上排正文；用物件揭示完成第一步说明，不额外画指示线 |
| K3／.78 | 首页已经退出；AI 左侧暗墙与右侧人物建立稳定配重 | 原“AI 行业观察”已在终态位置建立，原简介开始可读；文字不继续跟相机漂动 |
| K4／1 | 原 AI 开场构图停稳；后续目录自然接在下方 | 原简介与三入口完整，普通链接、键盘和复制立即可用；后续阅读无镜头循环 |

具体时序采用有重叠的交接，避免每段等待上一段完全结束：

| 通道 | 进度与变化 | 作用与约束 |
|---|---|---|
| 首页文字 | p=.08—.30随原容器离开视野；可在最后一小段降低透明度 | 保持原起点；焦点或直接导航优先，不隐藏一个仍被用户操作的入口 |
| 绘画与遮挡 | p=0—1按同一相机路径求值；AI背景始终覆盖有效画幅，首页在前遮挡 | 不加大幅整图淡黑，不在画面空缺处用镜像／拉伸补底；停止滚动即保持 |
| AI标题 | p=.62—.72，透明度0→1，至多8px向上归位 | 使用原字体、字号和原包围盒；显示后固定。真实布局中须等首页前景下沿／实际遮挡轮廓完全越过标题包围盒再显示，名义阈值不能覆盖几何判断 |
| 原简介 | p=.70—.82，整段透明度0→1，至多6px归位 | 说明“AI如何进入真实生活”的原关注点；不逐字打印、不逐行追逐、不删改原文 |
| 三入口＋查看全部 | p=.78—.88作为一组透明度0→1，位置保持原样 | 不逐条飞入，不移动点击目标。隐藏入口退出Tab顺序；仅当焦点即将进入AI内容或显式导航选择AI时同步终态，普通首页Tab不跳章；直接访问目标显示终态 |
| 阅读释放 | p=.88—1画面收束；p=1恢复普通文档流 | 不突然补一段自动动画；能无限停留，继续下滚到现有#ai-reading |

任意属性的局部区间使用夹在0—1的线性p映射或同一确定性曲线，不再叠加时间惯性。若演示以约1.2秒匀速走完p，镜头约1.2秒，标题约120ms、简介约144ms、入口组约120ms；这些只是比例说明，访客慢滚可任意停住，快滚可直接略过。点击接受邀请可以直接到原#ai；减少动态直接展示K4，不走这段时序。

“说明动效”的观看顺序是物件→题目→完整句子→选择；这已足够解释章节关系。原人物面部、手指、手机和书均不做网格变形，不新增滑手机、翻书、转身。交接不能以演员动作尚缺为由假装完成。

## 3. 字体搭配：保留角色，控制层级

已读取真实 CSS：Vagus 字标是 Times New Roman；中文标题使用 STZhongsong／华文中宋等宋体栈；正文使用等线 Light 等无衬线栈。这个搭配已有“展览标题—日常阅读”的区分，本轮不换字体，也不把参考4的展示字形伸缩直接套在中文上。CSS字体栈只是候选，不证明每台设备上实际使用相同字体；未发现本项目自带网页字体资产，正式跨设备字体一致性与授权仍待核验。

| 文字角色 | 当前依据与本版保留方式 | 设计与验收要求 |
|---|---|---|
| Vagus 字标 | Times New Roman，原字号与负字距 | 不变成章节转场道具；首尾与原页一致 |
| AI中文标题 | var(--serif)，原clamp(43px,4.5vw,76px)、行高1.3、字距−.04em | 整个词组轻揭示；不压扁、拉长或拆字。字体变化导致挤压时重新核对字宽，不靠scaleX修复 |
| AI简介 | var(--body)，原15px、行高1.95、最大440px | 原文一次显示完整；保留连续段落，原版位不另做卡片 |
| 三条入口 | 原宋体24px/1.5、原竖向间距 | 全组出现后静止；箭头不跳动，触屏不依赖悬停 |
| 章节标签、导航 | 原无衬线与当前尺寸 | 沿用原层级，不把小字加宽成装饰墙；重要信息不能只靠11px标签承载 |
| 未来长文正文 | 当前尚未接齐原文，本轮不改原页面字号 | 接入真实文章时建议无衬线16—18px、行高1.75—1.85、约34—40个汉字／行；具体值按实际内容试排，不能当本轮已实施 |

借参考4的是标题与主题、画面发生有意义的关系，不是任意字形特效；借参考2的是媒介统一，不是再添一套手写字体。不得为完成“字体搭配”检查擅自下载、打包系统商业字体。SVG用可用系统字体近似排版，未证明浏览器中最终回退字体完全相同。

## 4. 阅读布局与反向返回

首页与 AI 的静止端态复用原 HTML/CSS，不搬动字标、理念、邀请或三入口。AI标题、简介和入口沿同一左轴约6vw排列，内容宽43%、上限700px，简介限制440px；右侧保留学者和手机古书的受力关系。原排版保持足够开阔，不能把标题巨大化到侵入人物脸和手。

进入#ai-reading后，以现有目录接管；未来原文页采用稳定阅读列，标题、导语、图像及说明围绕同一轴排列，只有内容需要时才扩展图宽。人物不强制缩成每章同样的右侧小图，不为“展览感”不断重排长段落。文章未接齐时仍如实保留缺口，不生成假封面、指标或正文。

原链接保持：SeedRealtime→ai.html#seed；Vibe Coding→ai.html#vibe；AI产品榜与热门精选→ai.html#selection；查看全部作品→ai.html。反滚先回到AI静止区，再逐步还原首页；文章返回恢复来源位置，直接hash到AI和减少动态都到完整阅读状态。停滚时没有文字或相机惯性漂移，后台暂停装饰更新。

## 5. 素材、画质与控制权

沿用 v3 的素材清单与“待审计”状态：两张完整webp已核，其余透明接触组、去人物背景、边缘延展、阴影与锚点均不能预设通过。首页人物—手—电脑—桌面—猫杯及接触阴影共享支撑链；无真实几何约束时合成同深度接触总组。AI人物—手—手机—书—桌面同理。独立背景的对位和终态反投影须逐帧验证，不只检查首尾。

原图仍约1672宽。1920×1080、DPR1.5、M≈1.326时需求约3820像素宽；1440×900需先考虑cover，等效原画显示宽约1599，需求约3180像素宽。这里的改进是减轻v3的约9.26K全幅等效需求，并不证明现图已满足正式画质。AI背景还要另算满幅cover与外扩，不能拿主体放大倍率当背景预算。

Three.js负责有限相机、接触组深度和遮挡；分层绘画负责外观；HTML负责文字、入口与阅读。旧scene-motion和新交接控制器不得同时写同元素transform/opacity/clip；一个控制源派生图像与文字状态，导航和hash独立可达。没有新网站代码、依赖安装、Remotion影片或新素材生成。

## 6. 验收与当前边界

本版看图时重点检查：①满幅AI环境是否比小矩形更能接住空间；②手机／书先显露是否自然引向原简介；③标题出现后位置稳定，阅读不中断；④原页首尾布局保留；⑤近景未过度放大、接触关系与补底真实。连续滚动还须另测停顿、反向、快跳、字体迟到、视口变化、200%文字缩放、焦点、减少动态及失败后备。项目四帧模板继续沿用v3中的F0—F3语义映射，本轮五帧是交接段的更细采样。
