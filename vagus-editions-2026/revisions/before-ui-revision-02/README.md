# Vagus · 四幕网页原型 v1

入口：打开本目录的 index.html。无需安装依赖，无外部字体、跟踪脚本或联网资源。需要HTTP预览时运行 `node server.cjs`，只监听127.0.0.1，并打印随机本机端口；退出该进程即关闭预览。未发布到外网。

## 本轮实现

首页、AI行业观察、START、Hug串成一页。首页无白色对话卡，三个选择从第一帧可用；继续对话切换为已提供的Vagus介绍。字标右侧横排理念，标题使用本机华文中宋，正文使用等线Light；未安装时由浏览器替代，不分发字体文件。

作品速览、章节导航、文章索引、项目正文、上下幕与回到首页均为真实锚点。文章原文、产品界面、简历未接入的入口明确显示说明，不虚构成果或跳转。缺失入口不等于正式作品链接已完成。

桌面START/Hug有不超过0.75视口的滚动推进：画幅内拉开、标题让位、独立阅读面接入。START采用轨迹线和票边式阅读面，Hug采用水平边界，均停滚即停、反向可回。AI保留完整可点击文字作品入口，以短幅图像取景交给文章索引。无滚轮劫持、计时影片、声音、持续循环。

**素材能力限制：** 现有艺术图为单层完成图。没有独立人物、干净背景、深度图或真实3D；人物眨眼/手机手指滑动/递票局部动作尚未制作。路线线条是叙事提示，不是实际START地图；Hug边界不是已接入的真实花园。这些都不能通过CSS伪称完成。

减少动态遵从系统偏好，也可在顶部关闭。窄屏或低高度视口取消驻留，内容保持普通文档流；脚本失败仍有全部标题、目录、项目说明与原生锚点。画面是增强层，不承载网页文字。阅读不计时结束。

## 文件

index.html内容结构；style.css四章视觉；app.js浏览器交互；state.js纯状态与采样函数；assets为压缩网页素材和来源hash；server.cjs仅本机预览；tests为自动测试。PLAN.md记录实施与GitHub参考审阅；VALIDATION.md记录实际验证边界。

## 可重复检查

`node --test tests/*.test.cjs` 运行状态和HTTP边界测试。`node scripts/check.cjs` 检查锚点、本地资源、脚本语法及原稿hash。HTTP测试需要允许本机回环访问；受限沙盒EACCES不是页面功能失败。图片再导出脚本依赖本机Codex运行时的sharp，浏览网页本身不依赖它。

## 来源与发布边界

四幅图来自此前用户要求生成的Vagus试稿，源路径与SHA-256在assets/manifest.json。未复用Shopify/Contra的画作、品牌图或源代码。当前学者是古典人物再诠释，不声称忠实复刻罗丹。公开发布前仍需审查艺术资产使用范围、字体授权、真实内容的公开权限以及最终署名。
