# Vagus · 思想者三维灰模 01

这是已确认“绘画空间＋真实三维前景”方案的第一阶段：手/前臂、手机、打开的书、桌面与袖口定位代理。手是有厚度的连续网格，由真实指节骨骼播放，不再拉伸原画。灰色材质用于检查形体；手机后续恢复橙红。尚不是完成的雕刻、美术融合或最终作品集页面。

## 打开与操作

需要已有Node.js。在本目录双击start.cmd，保留终端窗口，在Google Chrome打开 http://127.0.0.1:4180 。如果当前预览已启动，直接用该地址，不重复启动。Ctrl+C停止服务。服务器仅监听本机，不是公网发布；不要用file://直接打开HTML。

默认和近景只看见手机背壳/侧边；手机与书固定，食指5秒内约3次上划/回位，随后停2秒再循环。暂停按钮、离屏、后台和系统减少动态均停止自动推进。关键帧0/1/2.6/5.5/8秒是显式审阅模式，不代表实时播放性能。接触侧视角只供检查指腹与玻璃，不是网站镜头；页面有明确提示。原画对照在下方，已有作品集在4179保留。

assets/thinker-gray.blend是可编辑源文件；assets/thinker-gray.glb供网页播放。只播放不需要Blender、登录、联网、npm install或付费服务；必要Three模块和MIT许可证已包含。Blender程序本体不打包。

## 本阶段验证与缺口

18项Node检查使用真实导出GLB：单一连通手面、有厚度和真实骨骼、全手表面不穿玻璃、整轮指腹与玻璃的数值间隙在-0.02至0.08mm内、28mm上移、腕/臂真实表面固定、2秒静止、手机底部85处采样不穿书页且具有承托区域、书页外法线和默认/近景不露屏；另有时钟、加载保护及HTTP检查。实际隔离Google Chrome的10项检查覆盖GLB播放、五帧截图、7.8秒连续录制、暂停、系统减少动态、窄窗口与失败/上下文丢失后备，另有真实Chrome加载取消检查，确认等待中的渲染器立即释放，见VALIDATION.md。

造型仍简化，指节、掌部轮廓、指甲和袖口尚需艺术审阅与打磨。没有将灰手合成进原画，没有制作最终绘画纹理、整房间浅浮雕、F2滚动镜头或其他章节三维。真实设备、其他浏览器、持续帧率与用户视觉接受仍未完成。不能把通过数值检查解释成已达到Shopify画质。

## 复现

```bat
node --test tests/*.test.mjs tests/*.test.cjs
node server.cjs
```

重建资产：使用原项目同级toolchain/blender-4.5.15-windows-x64/blender.exe，以 --background --python-exit-code 1 --python scripts/build-gray.py 运行；导出源文件和GLB并渲染静帧。便携包在其他目录重建时自行提供Blender程序。scripts/browser-review.cjs使用本机已有Playwright测试运行时，路径写在脚本中；播放网页和Node资产测试不依赖它。

本批全部输出在D盘；原画、旧模型、旧站与历史ZIP保留。执行记录见progress.md，来源见SOURCES.md。
