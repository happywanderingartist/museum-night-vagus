# Vagus · 两屏试稿 v2

首页保留 v1 蒙娜丽莎底图，SHA-256 核对原样。移除白框、浅色气泡和全局背景洗白。品牌使用紧凑 Times New Roman 衬线字标，中文使用 Microsoft YaHei；工作理念在 Vagus 右侧横排。底部仅做局部电影暗部，对话与三个纵向选择直接融入场景。

对话从蒙娜丽莎开场白进入 Vagus 的原文邀请。三个入口从第一帧即可操作，不强制等待、不打字机、不循环。默认 PNG 展示邀请帧，另附 opening PNG 展示开场帧。独立 UI SVG 可编辑，不烧进原画。HTML 是可点击试稿；PNG 是确定性 SVG 排版导出，不是浏览器截图，两者字体换行可能略有区别。

思想者改为完整冷色空间：前景石台、中景人物/电脑、远处建筑开口，统一斜向光源与接触阴影。大标题改现代无衬线，作品仅文字纵排。画面是 AI 生成的再诠释，不是 Shopify 原作、不包含第三方网站资产。当前纵深来自绘画，不是实时 3D；真实视差还需要干净底图、人物和前景独立素材。

色彩：石蓝 #152832、暗影 #07130F、骨白 #F1F0E8、冷灰 #D0DADB、绿灰 #D8E2D3。主要记忆点是名画角色与单一现代电脑，不额外添加装饰系统。

动效边界：本轮只实现点击切换与轻微选择反馈；未实现快速滚动章节转场、独立角色动画、WebGL 或性能验收。减少动态偏好关闭过渡。未提供简历、文章原文与链接，不编造详情。
