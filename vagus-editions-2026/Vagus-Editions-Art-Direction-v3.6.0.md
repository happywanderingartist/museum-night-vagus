# Vagus：当代行为，而不是复古设备展

先读 [章节个性与研究迁移](references/chapter-personality.md)。用户已确认思想者改当代橙红手机，下一批制作START与Hug的F0–F3。旧版打字机是失败探索，不当正式结论；旧参考中固定电脑、优先B、冷灰示例均不覆盖本轮明确选择。

## 当前约束

品牌只写Vagus。理念横排在字标右侧。首页保留蒙娜丽莎生活工作室、粉色笔记本、冰美式与无白框游戏选择，入口不等待台词。标题与正文区分：当前宋体展示标题、细无衬线正文，调用真实可用字体，授权另核验，不横向压扁字形。

AI章节保留“AI行业观察”、小尺寸连续简介、三条竖向纯文字入口和普通“查看全部作品”链接。不加卡片、气泡、装饰注释、复盘或未经核实的数量。思想者目前是古典学者式再诠释，不能宣称罗丹原作忠实复刻。当前现代物件是橙红壳手机，支在古书上，托腮与准备滑动形成动作关系；不再添加电脑或打字机。

## 决策顺序

1. 打开真实原稿和参考，区分像素观察、制作方自述、推断与自己的提案。截图不证明完整动效体验。
2. 一句命题说明角色正在做什么当代行为、与作品类别有什么关系。去掉解释文字仍能读出反差。
3. 先排角色、物件、字与明暗重量，再做颜色和媒介。不是先抠主体再填背景。
4. 同时安排整站章节节奏：相邻页至少两项变化，主色、明暗、空间、动作或占幅；蓝墙粉电脑换成粉墙蓝电脑仍是同配方。
5. 空间感来自有因果的远、中、前、字四层和遮挡推进；背景必须回答“主体从哪里来、站在哪里、被什么挡住、下滚露出什么”。不能把自然风景或整页缩放当作 Shopify／Lusion 式纵深。
6. 制作无字画面与独立UI，再制作F0–F3。静态图、机制实现、浏览器实测和用户接受分别报告。

## 两条构图路线

A沉浸绘画：环境、光线与动作共同叙事，不是贴自然壁纸。适合START舞会、Hug清晨和AI阅览室。
B编辑裁切：巨大局部、材质交界与留白配重，允许安静底面，不强制补山树或完整建筑。适合几何运营、人物特写与作品伴图。

全屏、半屏、三分之一是随内容选择的占幅，不是每页重复把右侧人物逐次缩小。标题可以跨图配重，但不能挡关键字、脸、手或操作。现代不等于科技霓虹；非黄色不等于只能粉蓝、青绿或暗灰。

## 素材、动效和真实阅读

背景按 [背景美术合同](references/background-art-direction.md) 填命题、明暗骨架、中文安全区、光线/材质、边缘、远景和拉远露出范围。禁止空墙＋设备、厚重墙纹、全屏噪点和堆装饰替代设计。丰富度来自有因果的工作痕迹与空间。

分镜按 [分镜合同](references/storyboard.md)：F0静态可读，F1局部苏醒，F2叙事交接，F3真实作品阅读；入口始终可操作。F3缺真实资产时可交明确标记的阅读版位图，不能用生成界面、假指标、假音频或假现场充数，也不能报四帧成品全验收。

网站运动先读 [动效研究](references/motion-study.md) 与 [动效合同](references/motion-contract.md)。需要近景拉开、差速、字图交接时使用 [效果配方](references/effect-recipes.md) 和 [素材能力合同](references/asset-contract.md)，不静默降成整图缩放淡出。分清滚动驱动与自动播放，写明触发、端态、反向、中断、直接跳转、减少动态与失败后备。现有整幅PNG不是独立透明角色、干净底图或实时3D。

需要 Shopify／Contra／Lusion 式空间、固定视口、场景板推进或巨字穿插时，必须读 [空间、镜头与章节板](references/spatial-motion-system.md)。最简可行版本是一场景一舞台、归一化滚动进度、场景板遮罩和真实文字层；Three.js 只在独立资产、相机／骨骼动作、性能与静态降级都满足时引入。

## 检查与交付

[项目历史约束](references/vagus-constraints.md)、[真实视觉研究](references/visual-study.md)、[构图语法](references/scene-grammar.md)、[检查表](references/checklist.md)、[反例](references/anti-examples.md)、[来源](references/sources.md)、[调用指南](references/codex-guide.md)按任务读取；历史示例与当前用户选择冲突时以本页和chapter-personality为准。

只研究/只更新Skill时不擅自改站、生成或发布。制作时交无字母版、独立UI、F0–F3与缺口、来源/授权、提示词及实际验证范围。用户作品才是证据，艺术图只是入口。不能承诺仅靠Skill就获得参考站同等视觉或性能。

# 反面案例

背景专项：冷灰墨绿只能定义配色，不能证明美术成立；整屏颗粒不能代替色阶和视线组织；几何机制夹具不能作为背景已完成的范例。具体正向制作与验收合同见 background-art-direction.md。

| 反例 | 问题 | 修正 |
|---|---|---|
| 紫底太空，后面补远山 | 背景名词替代构图，媒介不一致 | 选 A 或 B，重排重量与光线／材质 |
| 所有画面必须前中远景 | 一种空间配方冒充艺术规律 | 编辑底面靠裁切与边界也成立 |
| 必须完整露脚 | 限制主体尺度和张力 | 保留叙事动作，允许有目的越界 |
| 复制 Contra 女性、网点键盘、青绿 | 照搬可识别表皮和资产 | 提取时代反差和媒介统一机制 |
| 宫殿换成紫色，卡片原封不动 | 换皮未改层级 | 删除竞争信息，重排主视觉与入口 |
| 电脑、手机、耳机、机器人齐上 | 笑点稀释 | Vagus 只留一个电脑关系 |
| 大字挡住关键标题 | 融合损害阅读 | 用基线、轮廓、尺度，不必遮挡 |
| Contra 有卡片就给 Vagus 加卡片 | 参考覆盖用户要求 | 研究记录事实，本页仍竖排文字 |
| Shopify 暖色就恢复金色大厅 | 无视项目非黄色限制 | 借章节变化，不照搬被禁色调 |
| 看截图声称所有动画已体验 | 证据越级 | 分开截图、导航、自述与未测指标 |
| 在原图生成导航按钮 | 修改与响应需要重画 | 无字图像＋可编辑 UI |
| 为填版编作品与“10+” | 设计变成事实来源 | 缺内容就停在方案 |
| 用很多三维技术证明像参考 | 成本代替设计 | 静态先成立，再为收益加技术 |
| 把人物后加一张自然风景，仍称 Shopify 式纵深 | 背景只在人物之后，没有遮挡、镜头与跨层关系 | 先定世界剖面和场景板，再让主体跨过前中后景 |
| 整张完成图统一 `scale + translate + fade` | 所有元素共面同速，看起来像海报缩放 | 分离背景、主体、字与场景边，分别定义取景和板移 |
| 每章重复“左字右人”或同一石像换色 | 章节变化只发生在皮肤 | 每章至少改变主色、明暗、动作、占幅或空间方向中的两项 |
| Lusion 有黑底粒子就全站铺黑底光效 | 复制表皮，丢失其可逆镜头与空间层级 | 迁移固定舞台、跨板遮挡和可逆进度，不复制视觉资产 |
| 把 WebGL 当作唯一内容容器 | 文字、导航和失败状态不可访问 | DOM 保留全部内容；WebGL 只做可降级的空间与装饰 |

## references\asset-contract.md

# 效果重建：素材与可实现范围

“套用”是让代理稳定选择构图、制备素材、建立时间线并测试，不是 CSS 滤镜把任意完成图变成参考站。先核验源图、目标效果和已有网页栈，再填写本表；缺图仍可写任务书／测试机制，不能声称正式视觉已通过。

## 每个章节的素材合同

| 项目 | 必填内容与验收 |
|---|---|
| 视觉命题 | 角色、现代物件、动作与内容的关系；一眼能理解的反差 |
| 场景底图 | 无 UI 的完整背景；说明被角色遮住处是否补全；使用权来源 |
| 主体与接触物 | 同一坐标画布内的透明主体与电脑；接触、阴影、遮挡可信；真 alpha |
| 深度结构 | 单图、独立图层、深度图或真实网格，明确拥有哪种；不把 PNG 称 3D |
| 端态取景 | 同一个素材在起／中／终帧中头、手、电脑的相对位置；原画幅外不能凭缩放补回 |
| 安静阅读区 | 起中终三帧均有文字安全区；中文实际排版，不能仅用英文占位 |
| 材料边界 | 直线、绘画边缘、纸边或其他与 Vagus 相容的方式；不是所有路线都用纸 |
| 质量与加载 | 实际像素尺寸、文件大小、同构图低清 poster、替代文本／装饰标记及失败策略 |
| 可变性 | UI 字体、标题、正文、导航保持 DOM／可编辑；三种画幅的裁切策略 |

所有分层应共享画布、透视和材料逻辑；背景重绘不能带入另一世界。主图文字已烧入时，先清理或重制无字图，不在上面再叠一套标题。未经授权不下载参考画作作为生成素材；研究截图不能当复用许可证。

背景项额外按 background-art-direction.md 记录明暗骨架、光线方向、材质密度、人物边缘与拉远露出范围；像素需求和文件预算按实际最大显示尺寸、cover、变换与DPR计算，不用通用几何底面冒充已制备背景。

## 能力分级，不掩盖差异

| 资产状态 | 能稳定实现 | 不能声称拥有 |
|---|---|---|
| 单张有背景完成图 | 在既有画幅内改变裁切、尺度，文字独立交接，边界转场 | 新视角、隐藏肢体、人物与背景真实差速 |
| 背景＋透明主体 | DOM 2.5D 差速、前景遮挡、近景到较完整取景 | 真实侧面／背面与体积相机绕行 |
| 图像＋深度图 | 有限位移平面的深度响应，依实际渲染验证 | 无孔洞的大角度转身或完整网格 |
| 纹理化网格＋相机／必要骨骼 | 真透视、可控视角及有资产支持的局部动作 | 未制备的背面纹理、未做绑定的手部动作 |

若目标需要独立人物运动却只有整图，制备“去人物干净背景＋透明主体”是前置任务；若用户要求真实 3D，不用 2.5D 冒充。思想者与电脑先可合成一层，避免差速把电脑从手里漂走。素材留足近景和拉远的裁切余量，不要求网页每帧露全身。

## references\background-art-direction.md

# 背景美术合同：从“简单”到完整画面

用于背景被评价为简陋、主体贴图感明显、拟达到参考站美术水准，或制备滚动主视觉。与 scene-grammar.md、asset-contract.md 配合；本文是 Vagus 迁移规范和试制建议，不是 Shopify／Contra 的官方参数。本轮只写 Skill 时不生成图、不改正式网页。

## 先定义背景在画面中的工作

背景是标题、角色、道具共用的明暗和材料系统，不是人物完成后才填的空白。先写“它如何把视线引向托腮与电脑、如何让字可读、拉远后有什么”，再选颜色和景物。低干扰是控制竞争，不是没有设计；留白也不必补满。

选择 A 沉浸绘画时，环境是命题的一部分，统一透视、光源、空气感和媒介；可以是室内、自然或抽象空间，不强制山树云。选择 B 编辑裁切时，以主次色阶、大裁切和材料交界组织；允许大面积近白或克制彩底，不强制前中远景。两条路线都不能用“加纹理／加风景／换颜色”替代重排视觉重量。

## 背景 brief 的必填结构

| 字段 | 应写成可制作的决定 | 不能只写 |
|---|---|---|
| 命题与路线 | 角色为何在此、背景如何承托动作；A 或 B | Shopify风格、艺术感 |
| 明暗骨架 | 主亮区、主暗区的位置与形状，视线落点；缩略图看大色块 | 冷灰墨绿、高级配色 |
| 文字区域 | 已有中文实际包围盒；每个关键帧的底面亮度与硬边位置 | 左半屏留白即可 |
| 光线 | 方向、软硬、阴影去向；电脑反射和石材接受同一环境色 | 柔光、电影感 |
| 材料分布 | 主体高细节区、背景低频色层及局部笔触；统一尺度 | 全屏加噪点 |
| 边缘 | 哪些轮廓清楚、哪些与底面弱化；接触处如何落地 | 全身羽化或发光描边 |
| 拉远终帧 | 可见肩肘、电脑、支撑面及完整底图；近景从它反推 | 缩小后再补画 |
| 素材与状态 | 同坐标画布、完整背景、主体／电脑、必要阴影、UI独立；已有／缺失分开 | 文件名存在就算完成 |
| 验收与授权 | 检查尺寸、关键帧、来源／授权、剩余缺口；用户是否接受 | 动画通过所以背景通过 |

没有实际素材时填方案坐标和待制备项，并标明是提案；不要虚构量测、通过的图像或作品内容。

## 一个可执行的思想者示例（不是已选方案）

**命题／路线**：长久思考的石质身体面对即时回应的电脑；B 编辑裁切，现代的雕塑感绘画，不是科技展厅。非黄色；冷灰、低饱和灰绿与石墨色只是此例的配色，可按用户后续要求替换。

**母版与重量**：1600×900 无字母版。左侧约 x=96–704、y=126–675 作为标题、简介、纵向排列文字入口的起始检查框；顶部品牌导航另留区域。主体主要占右侧，允许越出右／下画边，头、托腮手与电脑关系完整可读。这些是本例提案，不是官网测量、固定安全区或最终坐标。

**明暗与光线**：左侧是连续、低边缘密度的亮灰色阶；右后方一块宽而柔的灰绿暗面承托肩背，底部轻压暗建立重量，不增加第二个视觉主角。宽主光从左上方进入，阴影朝右下延伸；石材、电脑反光与底面接受同一色温和方向。若原人物素材光线相反，先统一制备或选匹配素材，不直接叠上此背景。

**材质与边界**：背景用薄层颜料般的大色阶，局部色层在主体附近可见；脸、托腮手、石材转折和电脑接触处保留细节，文字区不铺高频刷痕。头／手／电脑轮廓清楚，肩背局部用接近背景的中间调弱化，底座／承托处有可信接触关系。不要把整个人物模糊、加光圈或用黑色投影掩盖抠图边。

**空间与裁切**：本例不加远山、树林、柱廊、金色大厅。完整背景必须有与同一构图一致的色层与阴影，即使角色移开也不出现空洞。近景是完整母版的取景，不是另外生成的另一幅图。主体和电脑先作为一体素材，避免差速破坏接触；B 路线不要求补一整间房。

**对文字负责**：正式叠加“AI行业观察”、已有简介和三项入口检查，不能用英文假字代替。明暗硬边不切过小字，电脑高光不落在链接后；失败先调构图、裁切或局部明度，不加整屏灰蒙版，也不把字缩得更小。框会随真实字宽、字号和断点变化，逐帧重算。

此例只是一条完整方向，不默认要求另做多个配色版本，也不能代替实际成图审阅。

画面路线与动效强度分开记录。本例B构图默认对应 editorial 的1.04→1微幅取景；这不等于参考中明显的近景拉开。若要B式背景与大幅拉远，先另定主体占幅、标题安全区和时间线绑定，再实现验证；可以复用 immersive 的分段函数，但不能直接照抄其全屏布局／字幕／边界后声称已有独立的“B大拉远”方案。Skill目前未提供该独立profile。不得因为缺现成profile就静默把用户要求改成微差速。

## 素材制作顺序与生成合同

先确定拉远终帧及字图重量，再制作整幅无字视觉母版；构图和光线成立后，按同一母版制备无人物干净背景、真透明主体与电脑、必要阴影层及同构图 poster。分层是交付方式，不把背景和人物各自随机生成后拼起来。用户要求保留原图像素时先锁定保护范围，不借“统一美术”擅自整图重绘。

可交给素材生成的本例提示词：

> 为1600:900横向网页主视觉制作一幅完整的现代编辑式雕塑感绘画。右侧大尺度的思想者式石质人物托腮，另一只手与一台无品牌笔记本自然互动；保留头、托腮手与电脑关系，允许下身越出画面。左侧为低边缘密度、可承载中文的连续亮灰色阶，右后方以宽柔的灰绿暗面承托肩背，下方轻压暗建立重量。全画面共享左上宽柔主光与右下阴影方向，电脑反射接受同一环境色。背景以薄层颜料感的大色阶组织，细节集中于脸、手、石材转折和电脑接触处；肩背部分轮廓在中间调中自然弱化，关键动作边缘清楚。整体统一构图、媒介与材料，不是棚拍人物贴到风景上。图像中无任何文字、导航、按钮、卡片、气泡、品牌或水印；无黄色主调、金色大厅、额外设备、霓虹或装饰光圈。

生成前将尺寸、裁切、光线和配色替换为本轮已确认 brief；不要把这个示例当所有页面的固定提示词。只请求提示词时不执行生成。

## 为网页运动预留真实图像

按原生时间线检查 p=0/.25/.5/.75/1：主体取景变化、文字区域、角色移开露出的干净背景、材料边界和正文接管。先用最终露出范围做完整底图，再反推近景。最大缩放、位移、object-fit:cover 与断点共同决定余量，不统一加一圈空白或用棋盘格补边。

接入3.1.1模板时，背景与主体都映射到全幅共享画布；右侧主体已在母版中定位，不能再将两层整体塞进右半屏。模板四边默认外扩24 CSS像素以覆盖自身位移，必须用真实图像内容填满，所有分层保持同一外扩与cover映射。修改位移／缩放后重算余量；制作坐标以最终浏览器裁切为准，不能把母版1600×900的坐标原封不动当视口坐标。

像素需求以最大真实显示尺寸（含 cover 与变换）乘所选 DPR 估算。例如母版按1600×900显示、主体最大1.24倍、DPR1.5，需求约2976×1674，可从3200×1800素材起试；这不是已生成资产，也不表示低分辨率图仅放大导出就获得真实细节。实际视口、裁切改变后重算。

文件预算按实际质量与加载测试决定；首轮可试 poster≤160KB、首视口主视觉图像合计≤2MB，均为项目试制预算，不是参考站指标或必须压到模糊的硬门槛。透明边缘、色层或文字后方出现压缩损坏时，记录取舍并调整格式／裁切／加载，不默默牺牲画质。无正式资产时只能标预算待测。

## 背景验收：四种观看方式

1. 隐藏UI、缩到约400px宽：应有明确大色块主次和角色落点；添加噪点后才“丰富”的稿件先返工构图。
2. 原尺寸叠真实UI：逐文字区域核对明暗与可读性，普通文字至少4.5:1、大字3:1；复杂底面分区检查，不能只算一个底色。
3. 对人物边缘作100%与200%检查：发白／发黑轮廓、锯齿、糊边、方向相反的阴影、多余肢体不通过。透明素材须查真alpha；完整背景不要求透明。
4. 在关键进度与窄屏裁切中看整幅画：没有露底、突兀补绘、纹理尺度跳变、人物电脑脱离或背景硬边扫过正文；减少动态时仍是一幅成立的静态画面。

这些是待执行的验收动作，不是写完brief就算通过。分别报告“规则已更新／素材已制作／视觉已审阅／用户已接受”；几何夹具与单元测试不能承担后两项证明。

审阅时另交同画幅对照记录：参考如何建立第一视觉落点、明暗怎样支持文字、主体边缘如何衔接底面、材料细节如何分布、拉远后空间如何保持完整；逐项写本稿的可见处理、差异及待改处，不能以“都用了古典人物、绿底、颗粒”判定相似，也不用伪精确总分包装审美通过。缺少成图或原始参考时保留待审状态，不称“参考级”。

## 反差与丰富度

每幕一个主行为焦点，不等于全站同一种设备。用视线、手势、受力和物件关系表达笑点，不靠解释气泡。一个当代动作比堆电脑/耳机/手机更有效。古书、纸稿、桌角和门洞只有承担工作痕迹、视线引导、观看位置或空间叙事才保留。

## 先填效果矩阵

每行填目标、参考证据、所需资产、实现方式、0/25/50/75/100% 画面、实测状态和缺口。用户指定的核心效果不能都降级成 fade。

| 目标 | 选择的机制 | 关键限制 |
|---|---|---|
| 近景到较完整取景 | 同坐标图层不同缩放与位移，或真实网格相机 | 单图不能找回画幅外人物；不要不经说明把它叫相机绕行 |

| 编辑式留白与局部裁切 | 短幅图层差速，主标题保持正常阅读 | Contra 路线不强制巨字消失或纸边 |
| 页级入场、悬停、局部循环 | 独立 time／hover／idle 通道，明确复播规则 | 与滚动通道不互相重置；素材／具体机制未验证时标待制备／待测 |

最后一行在本包中是合同要求，不含原站完整预加载或 Rive 实现；有逐项需要时再为该效果制备资源，不能宣称当前模板已覆盖全站。

## A：沉浸式章节的分段进度

将章节的可滚动长度归一为 p：clamp((scrollTop - sectionTop)/(sectionHeight - viewportHeight),0,1)。参考模板 section=200svh，sticky stage=100svh：总新增推进约一视口，p=1 释放，后续正文继续普通文档流。它服务三段不同叙事，不是多屏空白；用户快速跳过不被拦截。内容放大后容纳不下时应减少驻留或转静态，不强行挤进舞台。

| p 区间 | 主体／背景 | 字图与材料 | 稳定状态 |
|---|---|---|---|
| 0–.24 | 主体由 1.24 向 1 拉开，背景由 1.10 向 1，差速而非整图同动 | 巨标题从 .10 开始退出，.30 结束 | 开场已有语义标题与可用链接 |
| .24–.55 | 拉开至更完整的原素材取景；主体位移16→-8px、背景0→-12px | 说明在 .24–.40 进入；图像仍连续 | .40–.62 为说明主导状态 |
| .48–1 | 图像保持，不靠全屏淡黑掩盖交接 | 阅读表面从底部升起，材质边缘可替换；说明 .62–.74 退出 | p=1 阅读底覆盖画面并连接真实正文 |

模板用分段线性映射随滚动更新，不增加弹簧滞后。它是 2.5D 摄影视觉近似；相机轨道、骨骼和着色器不是这几行 DOM 代码自动获得的功能。纯装饰背景和边界 pointer-events:none，入口在安全前景层且语义链接可用。

说明是上方独立前景层，不是被阅读边界剪切的文字；模板在边界到达说明安全区前结束其显示。若实际中文排版更高，应改说明宽度／位置或提前退出，不让浅字叠到浅底。边界终点上移额外6%消除不规则顶缘漏图。链接区域先被阅读底覆盖，navTone 因而提前换深色字；正式全局目录应按自身背后区域计算，不照抄此阈值。

终点不能是一整屏无内容的浅色。夹具的 reading-intro 展示“阅读阶段”测试文字，正式接入替换为真实作品标题／已有短导语，不能原样保留或凭空新增个人经历。完整正文仍在正常文档流；真实标题只保留一套语义，不用复制假正文填满舞台。阅读入口不放在 pointer-events:none 的边界层，仍用可聚焦前景导航／正文链接。用户不允许额外说明时，只用已有真实标题，调整材料推进与正文相接的位置，而不是塞新文案。

夹具边界层整体 aria-hidden，其短标题只是视觉预告；正式接入若采用视觉副本，从真实内容生成并保持 aria-hidden／无可聚焦控件，真实标题和正文必须始终存在于后续正常文档流，静态后备不能丢失。也可不用副本，改为让真实正文更早进入视口；无论哪种方案都不能留下空白镜头作为终点。

## B：编辑式页面

普通文档流不强制驻留。背景位移0→-8px，主体1.04→1、0→-20px，标题／说明不按时间消失；下一内容自然进入。该微差速仅为初值。若目标是独立拼贴图像，按每片真实边界与裁切分别定路径，不能把整页套同一个幅度后声称复现了原站。图像与正文的编排仍须先静态成立。

3.1.1 的 B 进度从章节顶部到达视口顶部开始，到章节底部到达视口顶部结束：p=clamp((scrollTop-sectionTop)/sectionHeight,0,1)。不使用 A 的 sectionHeight-viewportHeight 分母，避免短首屏永远停在0；进入视口前保持起帧，退出完成终帧。不要为了微差速人为延长首屏。页面滚不到完整终帧时，以实际可达范围检查，不能用采样按钮代替原生滚动。

两种路线的背景与主体均使用全幅 `.vagus-art`，主体偏右由透明素材的母版坐标决定，不再把整个美术容器裁为右55%。左侧明暗色层属于背景，不能留给单一底色替代。默认各图层共享24 CSS像素的外扩画布与相同object-fit／object-position；这会轻微放大母版，文字安全区须在外扩后的实际裁切上核对。同一画布所有图层一起外扩，不单独扩大背景破坏静态对位；素材必须含真实边缘内容，透明空白不是背景余量。默认24px覆盖包内最大20px位移；修改变换后按全进度、实际尺寸重新计算，不把24px推广为任何动画的通用值。

沿用夹具标记：data-profile 为 immersive 或 editorial；data-layer 为 background、subject、title、description、reading；vagus-stage 内分层，真实作品放在舞台后正常文档流。替换几何层为已核验无字素材，设置共享画布与裁切、字体与真实内容。背景／主体素材缺一时先别宣称独立差速已完成。

preview(p) 仅供夹具确定性采样，不能接管真实用户滚动；重新滚动会恢复当前原生进度。destroy 清理监听器、observer、帧请求并恢复本模块设置的样式。不能把 demo 采样截图当原生滚动、参考站或正式页面已验收证据。

## 必须单独实现的网页系统

导航从中心到侧栏不是“放个固定左栏”就等价：用同一语义目录，或让视觉副本 aria-hidden／不可聚焦；定义起终矩形，按实际字体与换行重算。保留一个可操作目标，不让视觉副本成为第二套 Tab 顺序。对比色跟阅读底状态同步，hash／后退独立于动画。模板只输出 navTone，站点全局导航要显式消费它，不能宣称自动接好全站目录。

预加载只等待当前视口关键资产，优先同构图 poster，不阻塞导航和真实正文。需要“加载动画衔接角色动作”时须有连续端帧与相同资产，不能随机开场动画播完后硬切另一幅画。取消／跳过／回访要直接终态。局部 idle 离屏、页面隐藏或减少动态时暂停；hover 只在 fine pointer 开启，触屏和键盘仍完整可用。

## 图像相似度验收不是运行时单元测试

先按相同画幅比较三至五个关键进度：主体占画幅、关键手势位置、标题与主体关系、前后层差速、边界推进和正文稳定。记录参考观察、自己的重建与仍不同处；不复制受保护角色或布局来追求像素一致。几何夹具通过只证明机制能跑，不证明美术达到参考水准。

再实测原生滚动、停止、反向、快跳、hash、后退、字体就绪／图片加载／resize、路由卸载、窄屏、减少动态与失败后备。示例1024px只是夹具值；迁移时按内容安全区同时修改 runtime 常量与两处 CSS media query，不提供只改一侧的断点选项。最后才给“功能通过／视觉待审／用户接受”三个独立结论。

# Vagus 网站动效合同

这是2.1的轻量编辑页兼容合同。要求接近参考站取景与分层转场时，优先 effect-recipes.md 的3.0效果重建模式；本文件“首版不驻留／轻淡出”不适用于该模式。

这是可交接的 P 提案，不是参考站参数、用户已接受方案或已实现网站。结合真实代码／素材后再确认选择器、布局端态与设备测试结果。目的：让思想者的视觉命题过渡到真实作品阅读，不让访客为动画等待。

## 每个效果必须交付的字段

ID／目的；证据等级；驱动（时间、滚动进度、进入视口、指针或导航）；触发对象与阈值；起止状态和属性；滚动容器与区间或时长／曲线；文字阅读终点；反向／重复／中断；直接链接与焦点；断点变化；减少动态与失败后备；验收动作与证据。

缺站点数据写“待接真实代码”，不要编选择器或内容。滚动区间使用相对位置定义，而非未测的绝对像素。分清 image-transform、标题文档流和入口交互，不把整页装进一个动画。

## 建议执行合同：编辑式思想者

设 H 为当前视口高度，S 为作品阅读区顶部相对文档的实际位置，p = clamp((scrollTop - (S-H)) / (0.5H),0,1)。该段不增加空白占位、不锁滚动；S 由真实内容布局决定，字体就绪、图片尺寸变化、容器重排和窗口变化后重算，直接同步当前进度而非重新播放。首版不做图像驻留；以后确需驻留须另定起止与释放状态，不能只写“短驻留”交给开发猜测。

| ID／目的 | 驱动、起止属性与曲线 | 阅读与异常规则 |
|---|---|---|
| M00 首帧可用 | 不动画导航、标题、简介和三个文字入口；默认 opacity 1 | 图片未到先有定尺寸 poster／底面；不设阻挡内容的预加载门 |
| M01 图像建立 | 低分辨率同构图 poster 先完整显示，高分辨率图就绪后上层 opacity 0→1，240ms，cubic-bezier(0.23,1,0.32,1)；不淡出整个页面 | 每个浏览器标签会话一次；用户已滚离开场则直接终态；失败保留 poster，不空白。两层须同取景同尺寸，不做不匹配场景的强行交叉淡化 |
| M02 主视觉让位 | 宽屏图像层独立包装，随 p：translateY 0→-32px、scale 1→0.96、opacity 1→0；以 p 线性插值，无弹簧滞后 | 0.5H 内完成，正文保持正常文档流。停滚保持，反向重算，跳转不强制播完。标题与入口不逐字消失 |
| M03 作品出现 | 第一件真实作品的标题块顶部由下向上越过视口 85% 高度时，作品层 opacity .85→1、translateY 12px→0；180ms，strong ease-out 同 M01；同一阅读段只播放一次 | 以标题块位置触发，不用长文章可见面积比例。内容本来就在 DOM 且可读；直接 hash 到达或快速滚过阈值则直接终态，返回不反复闪；触发后继续到终态，不误称与 p 同步 |
| M04 入口反馈 | fine pointer + hover 环境，下划线 scaleX 0→1，origin left，160ms ease；焦点框立即出现、不做运动 | 使用语义链接，目标不平移；触屏不依赖 hover；点击直接导航，不等出场动画 |
| M05 章节定位 | 当前章节标识／必要明暗色切换可立即更新；普通浏览锚点走原生行为 | 尊重 URL hash、后退、跳过导航和焦点。键盘／减少动态不强制平滑滚动，不把聚焦和滚动混成镜头效果 |

M02 的 scale/translate 应施加在图像层，而不是交互入口或含全文的容器；终态 opacity 0 的纯装饰层不能残留点击阻挡。装饰 aria-hidden，真实文字保留 DOM。图像与电脑保持同一接触关系，不能为制造动效把电脑从手中漂走。

这些数值是初版建议，不是不可改设计令牌。复用已有项目 token 优先；更改需说明目的与复核结果。对直接绑定 p 的动画不再叠加时间 ease／强惯性，以免停滚仍漂移；需要导演式非线性时写清 p 的分段映射。

## 断点与降级

先按内容测试宽屏两栏；当实际文本与主体安全区重叠时转单栏，不机械把整幅缩小。初始对照尺寸可用 1440×900、1024×768、390×844，均是待测尺寸而非已通过断点。单栏取消图像驻留与 M02 位移，图像在文档流，作品直接跟随，不以移动端戏剧性牺牲阅读。

prefers-reduced-motion：M00 完整显示；M01 直接终态；M02 取消空间变换与驻留，静态文档流；M03 直接可见；M04 保留下划线／颜色即时反馈；M05 原生即时定位。页面隐藏时暂停纯装饰循环。首版不需要持续旋转、鼠标跟随或 WebGL；未来确有深度收益才另设预算和静态 poster。

## 技术选择与审查

CSS 负责颜色、透明度、反馈；IntersectionObserver 或现有库负责进入触发；若确需连续 p 才用原生滚动时间轴／Motion scroll，并验证支持与回退。不要同时装多个滚动控制器。复杂相机、rigging 或 shader 明确带来收益后才考虑 R3F／Three／时间轴；不能因为参考用了就必须引入。

优先 transform／opacity 减少布局成本，但不承诺“必定 GPU／60fps”。蒙版、模糊、大图层和显存都要测。用图片尺寸预留空间，避免加载布局跳变；正文和链接不依赖 canvas。没有性能记录不能报通过。

## 验收脚本（执行动作，不是程序代码）

正常与慢网首开；滚到 p≈0/.25/.5/.75/1 截图；停滚和反向各查；快速跳过、直接 hash 进入、浏览器后退、重载、键盘 Tab/Enter；文字放大后检查遮挡；减少动态和窄屏；素材／脚本失败；真实设备性能与低端情境。分别记录状态正确、视觉可读、功能可达与实际性能，未做项明确待测。

首版必须交付可运行的局部网站验证面与上述状态证据，才可称动效实现完成；图片、分镜和技能安装均不能替代。没有真实 Vagus 网站代码时先交合同，不凭研究请求擅自搭建或发布整站。

本轮真实操作：首屏、向下导航、Sidekick 锚点，以及从 Sidekick 两次受控 PageDown 的终态截图。首次对 body 发 PageDown 跨至 Marketing／Product Network；之后聚焦目录再发 PageDown 得到分段状态。前者不能当作一视口距离，原因未确证。DOM 观测到一个约覆盖视口的 canvas；canvas 自身 computed position 为 static，因此不据此断言它自身 fixed，可能由祖先定位。

从浅底正文 PageUp 返回后，恢复了人物、说明文字、视频入口与撕纸边界的组合，验证该段可反向返回而非一次性消失；仅验证终态恢复，未测逐帧可逆或精确相机轨迹。

## 2026-10-30 Shopify 补充

完整加载后重新检查首屏、Sidekick、Agentic、中段和阅读区：首屏是两位古典人物从左右进入、围出中央透明文字框；章节先让巨大无衬线标题穿过人物，再让人物取景、产品卡、手持手机和说明依次进入，最后切到浅色长表格。它不是每屏换一张背景，而是一个章节内多次改变主体层级与取景。官方技术线程说明 Painting 为独立 R3F Scene／Portal，背景较平的场景使用深度图位移，立体物件则用生成底模、Substance 贴图、Blender 绑定和 GLTF，并配 Theatre.js 时间轴、CSS／SVG 首屏、Rive 悬停和四级质量降级。

## 判断驱动的方法

先记录输入与画面状态。滚动小步 → 停止 → 原地等待 → 反向 → 直接锚点进入。随位置回溯的是 scroll-linked 候选；进区后停滚仍自行结束的是 triggered/time 候选；原地持续周期变化是 idle 候选。一段可能混用。两个终态截图不能证明相机路径、缓动、精确速度、FPS 或循环周期；无法连续取样就标 U，研究仍可输出 S 与 P，不冒称复刻。

记录原始时间、输入方式、实际滚动位置、视口、页面／章节、静止对照与截图路径；工具等待时间不是动画时长。CSS／WAAPI 元数据不能覆盖 canvas 内部动画。仅当工具允许且确实取得数据时报告测量值，不能为补证据绕过控制入口。

对固定视口网站，`window.scrollY` 不是进度证据：Lusion 的滚轮改变了场景，但原生 `scrollY` 始终为 0。应同时记录滚轮次数、输入间隔、可见 DOM、Canvas 状态与截图；不能因滚动条不动就断言没有滚动。

## references\scene-grammar.md

# 构图与媒介语法

背景制作与“简陋”反馈按 background-art-direction.md 填完整brief及四种验收视图；本文件保留路线判断，不以“低干扰／材质统一”几个词代替制作决定。

删除旧版“必须前中远景、必须全身、必须冷色”的通用要求。先读 visual-study.md，区分实际观察和迁移提案。

## A 沉浸绘画

环境参与命题，人物方向、建筑或云层的明暗给标题留位置。真实空间需要一致透视、接触阴影和光线，但不必每层都有可点名的山树云。Shopify 的环境属于整幅画，不是可替换壁纸。允许角色越界和裁切，动作信息比露脚重要。

## B 编辑裁切

底面可以近白、深色或克制彩色。一个巨大裁切主体与标题、留白、少数媒介痕迹相互配重。有效背景可能只有色阶、颗粒和边界处理，不需要完整风景。Contra 的网点与绘画交界把现代物件嵌入同一语言；迁移“统一处理机制”，不复制女性、网点键盘、青绿和标志。

## 共同检查

先在约 400px 宽缩略图看重量，再以目标尺寸检查字和边缘。关闭 UI 图像命题成立；打开 UI 正文仍可读。灰度看对比，模糊看大色块，不增加纹理掩盖结构。素材可留裁切余量，网页不必展示所有余量。

底面、主体、电脑与字共享材质／边缘／光线逻辑。编辑拼贴可以非写实，但须全画面一致，不能一半棚拍、一半油画、一半科技 UI。

## 中文字体

Contra 实测衬线标题的编辑感与 Shopify 大无衬线的章节力量不是同一答案。“AI行业观察”先做现代黑体与克制宋体样张，对比宽度、笔画、人物轮廓和可读性。用户要求换字体，未指定必须黑体；不得把一个英文字体机械当中文方案。字体文件授权另行核验。

# 空间、镜头与章节板

核查日期：2026-10-30。本文把 Shopify Winter ’26、Contra Labs 与 Lusion 的实际页面观察整理为 Vagus 可执行规则。页面观察、制作者说明和第三方逆向分析分开使用；不把三站的可识别画作、角色、品牌、素材或源码直接搬入 Vagus。

## 空间感首先来自世界结构

真正的纵深不是“人物后多放一座山”，而是观众能判断几样东西在不同深度上：什么遮住什么，哪些表面共享同一光线，前景和远景移动速度怎样不同，视线如何从一个平面穿到另一个平面。只把整幅图缩放、位移或加视差，得到的是平面推拉，不是可绕行的空间。

每个章节至少定义四层：

| 层 | 职责 | Vagus 示例 |
|---|---|---|
| 远景／世界底面 | 建立环境、明暗和历史语境 | 湿石板、暗厅、雾中水面 |
| 中景主体 | 承担主题动作 | 思想者、手机、托腮手臂 |
| 前景证据 | 越过主体形成遮挡，说明“镜头在里面” | 翻开的书页、桌面边缘、颗粒玻璃、垂下的布 |
| 字体平面 | 参与构图而非漂浮标签 | 巨型“思想者”、作品顺序、编号 |

层与层之间必须有因果：光线来自同一空间，接触阴影合理，前景遮挡不必把主体切碎。Lusion 中人物、粒子轨迹、反光地面和巨大字面共处一个镜头，人物跨越场景板边缘时仍显得在同一空间；Shopify 中人物、手机、商品卡与古典画共享同一景深，现代物件不是贴纸墙。

## 三站提供的不同机制

### Shopify：场景内取景推进

实际观察：首屏两位古典人物从左右斜向进入，中央透明框承担标题和目录；下滚后同一大画幅的章节标题逐步变大，场景元素重新取景。Sidekick 先出现巨幅章节字，随后人物、环形机械和现代设备进入前景；Agentic 从书房与 Mona Lisa 出发，现代手机、手持入镜、商品卡和说明依次接管；页尾再切到浅色信息阅读面。

可迁移：一个大场景不必靠多次整页淡出推进。让标题、人物、现代物件和目录在不同滚动区间进入／退出，各自有明确遮挡与速度关系；最后留出正常文档流阅读。

局限：其技术投入包括 R3F、分场景、深度图或 GLTF 网格、压缩纹理、Theatre.js 时间轴和多档降级。Vagus 不能因为“像 Shopify”就同时引入全部栈。

### Contra Labs：平面被切开，内容进入版式

实际观察：首屏是近白编辑底、左侧衬线大标题和按钮、右侧古典人物的大裁切；人物手中的现代电脑以网点与绘画相接。后续 “Taste” 让巨大文字在上方建立第二个视觉平面，“missing signal” 通过深青底色整屏切换阅读密度，并把三项统计卡放入实色底座。现代工具区块再用完整绘画、超大衬线和浮动品牌图标形成一层“物件从画里出来”的效果。

可迁移：纸张／色块／网点不是背景填充，而是把古典图像和现代界面压到同一材料系统的分界。阅读页可从艺术场景切到纯色底，而不是始终把正文压在图里。

局限：Contra 的证据主要是预加载与 scroll-triggered 展示；不能仅凭 Framer 就推定其所有动画采用同一种技术。

### Lusion：固定视口与场景板推进

实际观察：`v2.lusion.co` 的页面文档高度只有一屏，滚轮驱动内部场景；固定导航与 WebGL 在全过程保持。往下滚时，第一条深红抽象场景向上退出，蓝黑纹理段、白色雕塑头、投影墙、人物剪影和巨字依次跨过画面边界，下一个场景从底部接上。About 页中，线框跑者、粒子尾迹、反光水面与文字同步推进；后续画面转为黑白，场景仍连续。

官方项目说明：首页核心是可逆的实时叙事；滚动推动宇航员穿过入口并最终破开玻璃，点击可放慢，反向滚动会倒回；About 底部有 FLIP 流体模拟。另采用异步加载和压缩维持性能。

可迁移：用一个固定的“舞台”承载章节板，文字继续是 HTML；滚轮进度映射到相机、板缘和遮挡，而不是把整页 `scale()`。场景板可以从上下左右穿过，角色与物件可以横跨板缘，巨字可以前后穿插。滚动反向必须回放，点击不能只是装饰。

局限：第三方逆向说明提到 Three.js、GLSL、后处理、音频和自定义 Tween，但这些实现细节不能等同于 Vagus 已具备相同资产或性能；不复制其角色、构图、配色和素材。

## Vagus 的章节舞台规则

1. **先画“空间剖面”再画背景。** 标明远中前景、镜头轴、主光、遮挡和文字平面。背景必须回答主体从哪里来、站在哪里、被什么挡住、下滚后露出什么。
2. **一个章节只有一个主要空间动作。** 推近、横移、上翻、局部遮挡或水面响应选一个，最多再配一个轻量副动作；不同时做相机绕行、人物转身、粒子爆炸和多层字滚动。
3. **章节之间用场景板交接。** 下一章的底色或材质作为一条边从边缘推进，主体可跨边出现；不得靠全屏黑幕或统一淡出串联所有页面。
4. **文字属于画面结构。** 章节标题可以做巨幅前景平面、后景切线或沿透视扭曲的单行字；正文、链接和导航仍保持真实 DOM、可选中、可聚焦。用真实中文重新排版，不把英文大标题模板套到中文。
5. **用遮挡与差速建立层级。** 前景书页、装置边缘和光线可以越过主体；主体与接触物若没有分离资产就保持同层，避免手和手机漂开。远中前景速度差必须来自真实图层深度，不为视差而视差。
6. **阅读页要有自己的材料。** 章节场景后接纯色／纸／墨／暗底阅读区，正文宽度、对比和层级先成立。图像最终让位，而不是永远遮住内容。
7. **反滚与直达是系统功能。** 进度模型使用归一化 `p`，任何 `p` 都可直接绘制终态；浏览器 back、hash、快速滚过、刷新、减少动态都能对应画面。相机动作不能只在单次时间线上播放。
8. **导航永久可读。** 固定导航可随背光切换色彩或 blend mode，但不得被 WebGL 吞掉。移动端不把同一镜头硬塞进窄屏；优先静态重排与轻量板移。

## 最小实现分层

| 优先顺序 | 实现 | 是否必需 |
|---:|---|---|
| 1 | 一场景一固定／sticky 舞台，背景、主体、文字分离 | 是 |
| 2 | 原生滚动映射到 `p`，每层只控制位置、尺度、裁切和透明度 | 是 |
| 3 | 场景板遮罩与跨边物件，章节底色推进 | 是 |
| 4 | 前景遮挡与单层速度差 | 是 |
| 5 | 照片取景推移＋局部 2.5D | 可选 |
| 6 | Three.js 真 3D 或着色器 | 仅在独立资产、关键帧和降级齐备时 |

最小版本也能产生空间感：让下一章背景成为遮挡板向上推进，主体和标题以不同深度穿过板缘，再用前景书页或桌面遮挡一次视线。不要把整页图片塞进一个缩放容器。

## 每个章节的验收画面

- 0%：首屏静止可读，主体、现代物件和入口均清楚。
- 25%：至少一个前景层或场景边进入，主体仍完整。
- 50%：标题与主体发生一次空间关系变化，例如标题绕过肩线或从前景转为后景。
- 75%：下一章背景／材质从边缘接管，正文安全区建立。
- 100%：正常文档流显示阅读内容；反滚可恢复，直接进入和减少动态直接显示内容。

截图只能证明离散状态。要实现“接近参考”，还必须录制或连续抽样整段滚动的进入、停顿、反向、快速跳转与中断，并分别记录功能正确、画面自然、性能稳定和用户接受。

# 分镜与图层合同

本文是轻量编辑页的兼容方案。用户要求接近参考的取景拉开、差速、字图交接与材料揭示时，使用 effect-recipes.md 的3.0时间线，不以本表短淡化覆盖该目标。

比例指主图占宽；可分别用于不同章节，不强制同一角色逐次缩小。本表是 Vagus 提案，不是原站逐帧复刻。

| 状态 | 布局／阅读 | 触发／结束／反向 |
|---|---|---|
| 开场 | B 优先：右侧大思想者，左侧标题、自然段简介与竖排入口；统一安静底面 | 首帧可读，不等预加载才能操作；回顶同构图 |
| 进作品 | 伴图可半屏，也可退出，让真实作品成主角 | 短淡化／裁切，停滚稳定、反向恢复；不用强制缩小仪式 |
| 阅读 | 依内容用三分之一伴图或无伴图，正文足够宽 | 不按计时隐藏，键盘可用；无内容只交提案，不造案例 |
| 换章节 | 主色、场景、占幅可变，导航逻辑不变 | 可跳转；无动态时文档流；失败时全部静态可达 |

定时过渡可试 180–360ms，滚动过渡可试 0.25–0.6 视口：只是项目起点，非原站实测值；真实页面测试后决定，不硬凑参数。

图层：底面／环境 → 主体与有接触关系的电脑 → 可选前景遮挡 → 可编辑标题／简介／导航／入口 → 焦点。人物与电脑可先是一体素材保证接触，不冒充完整可编辑三维资产。

## 素材提示词

先指定路线、动作、占幅、取景、光线、媒介、边界处理和 UI 安静区，再写禁项。不要继续“中性棚拍石像＋任意背景”。原素材留关键部位与裁切余量，合成取景另定。B 可用真透明主体或融合底面图；A 统一制作环境与主体，不随机独立生成后拼接。无标题、导航、按钮、卡片、气泡、水印、品牌和额外设备。未授权生成时只交提示词。

# Vagus 当前约束 · 2026-10-23

已实际查看原对话两张 1672×941 合成稿：暖金大厅，右侧思想者与电脑，左侧 AI行业观察；分别有横排图片卡／透明文字卡，另有悬浮屏。它们不是独立人物原素材。没有独立整站首页、代码或作品库，不能宣称其他首页、导航功能已完成。旧批注坐标对应不全，品牌导航上移是可执行解释，不是假装完整恢复。

## 明确要求

保留“AI行业观察”，换字体，品牌导航置顶。简介缩小且连续自然段，不加解释。三项入口竖向、只要文字；不要图片卡、透明卡、底部注释、多余说明。暂不加复盘与经验。“查看全部作品”为文字链接，不编数量。现代而非科技感，不要黄色系，不同页可不同配色。既有导航不证明目的地存在，不补造作品、身份、经历或数据。

## 思想者

“竖排文字入口”指三个横排文字链接自上而下排列，不是把汉字改成纵向书写。用户之后明确撤销旧限制时可以更新本文件；若同时要求保留旧约束并加卡片，应先指出冲突。

命题：习惯长久思考的人遇到即时回应的电脑。托腮与一台无品牌笔记本关系明确，不加手机、耳机、机器人、气泡、悬浮屏、代码雨。默认主体偏右、文字偏左；允许裁下身／底座，头、关键手势与电脑应能解释动作。裁切不能像误切或掩盖肢体错误。

## 已否定与下一步

纯紫底＋较小完整石像＋普通大黑体被否定；失败是重量与媒介组织，不证明素底都错误。随后补山水暮景也被否定：棚拍主体、风景和字没有共同艺术指导，不能曲解成“还要再加一层景物”。

优先 B 编辑裁切：放大人物关系、减少无效空位、统一材质边界。若选 A 须整体组织环境，不沿用不匹配抠图。非黄色不等于只能紫蓝；近白、冷灰、青绿、墨色都是待比较方向，非用户已选色。

先给同一真实内容下的黑白重量稿和字体样张，再形成一个完整方向，不把换三个颜色当三种设计。旧版 1600×900 坐标仅属已否定稿初值，不再作为验收坐标。未核实文案和链接在交付说明标记，不在页面添加解释标签。

## 覆盖与限制

真实浏览器截图覆盖 Shopify 首屏、Sidekick、Agentic（Chrome），Contra 首屏、Offerings、missing signal 统计状态（Edge，已获授权）。截图与 Contra DOM 测量在交付 evidence/live-2026-10-23/，安装包不包含官网画面。未测全站逐帧动效、帧率、精确时长、全断点或所有悬停。

## Shopify

证据路径基准是研究交付根目录 Vagus-Research-v2，而不是安装后的技能目录；官网截图不随独立技能安装 ZIP 分发。只有安装包时，可按本文件观察与来源查证，不能声称本机已有这些截图。

首屏绘画自然环境中，左右动态人物与斜向动作围出中央阅读区；粉色现代物件和白鞋制造时代错位。中央细线框、混合字体主题、罗马序号目录提供秩序。环境属于画中世界，不是棚拍人物后的壁纸。

Sidekick 是深色星空／几何线、右侧绘画人物、前方电脑与环状天文仪器造型；巨幅浅色无衬线标题跨人物，左侧索引和顶导航保持位置感。大胆裁切与多个物件直接否定“必须全身、单物件”的全站定律。

Agentic 是暖暗建筑、拱／镜结构，人物左、现代设备右下，巨字跨图、次说明有书写感对比。背景并非总极简，色调不总冷；当前窄窗口索引拥挤，不复制密度而牺牲 Vagus 阅读。未测其精确字体名。

## Contra

首屏近白微颗粒底，左侧高对比衬线标题、简短正文和两级按钮；右侧古典画中女性巨大裁切，俯向下方网点化笔记本。青绿颗粒／像素连接绘画与设备边界。张力来自尺度、材料交界和留白，不来自风景。

Offerings 用青绿底、黑衬线标题，下方深青双列模块，近裁金色古典物件与白色标签。说明参考也用卡片，但不覆盖 Vagus 只要竖排文字的要求。

missing signal 放大绘画手部／首饰，斜向网点现代物件、白色说明及轮廓标签，下方浅色实底大数字统计块。局部图像、实底内容块和色调随内容变化，不是一个英雄图铺全站。

DOM 采样视口 1206×565：首屏 h1 Source Serif 4 Variable，64px/400；生态 h2 56px，模块 h3 32px；深字 rgb(43,43,41)、浅字 rgb(251,250,246)。仅是采样状态，非全断点规范。

## 迁移判断

共同点：命题先行、古典与现代有动作关系、巨大字图配重、稳定导航与变化章节。差异：Shopify 是沉浸绘画画廊，Contra 是编辑页面与图像实验。不混成“石像＋纯底＋网点＋山水”的清单。

Vagus 优先编辑裁切：放大思想者和电脑，保留托腮关系，有意裁下身；统一边缘和底面，重排标题与入口。若选绘画路线须整体组织场景。本轮是方案规则更新，未制作新图，未获得视觉接受。

## 动效边界

实际有锚点操作与多个页面状态，不反推精确速度。Contra 制作方自述定制预加载衔接英雄图、滚动动画；Shopify 制作者说明场景、时间轴和降级。详见 sources.md。“短转场、长阅读”是 Vagus 目标，不冒充原站测量。

## 2026-10-30 补充：完整首帧与跨章节状态

本轮用独立 Google Chrome 实例完成真实页面截图，不经过此前的 Computer Use 桥接。证据保存在项目 `research/2026-10-30-live-chrome/`；以下只记录可见状态与官方说明，不把局部截图当成完整交互验收。

Shopify 完整首帧中，两位古典人物从左右斜向进入，粉杯、粉色购物袋、白鞋和滑板横穿画面，中央细线框承托标题、简介、目录和罗马编号。Sidekick 的全屏状态让紫色面罩人物、环形机械和深空占据主体，白色“Sidekick”直接压在人物与物件之上。Agentic 先以 Mona Lisa、画框和商品卡建立场景，继续滚动后真实手持手机从右下进入、商品卡悬在画中，再让说明进入底部；章节后段则让位给奶油色信息表。Marketing 用一幅完整的古典风景承载巨大白色标题、斜体衬线说明和右上滑板影像。构图的重点是对象跨平面遮挡与尺度差，不是底色是否复杂。

Contra 首屏是近白编辑页：左侧衬线 H1、简短说明和两个按钮，右侧巨幅绘画女性与网点电脑；品牌字母 “contra LABS” 被拆成展览式标签。中段 “Taste” 用超大衬线字和下方多层纸卡形成第二套构图；工具区块让绘画、白底超大字和六个现代产品图标共存；“missing signal” 则整块切换为深青底，标题、正文与三张统计卡直接建立阅读层级。其图像、色块和文字边界比 Shopify 更平面，但同样强调“对象进入版面，而非背景装饰”。

Lusion `v2.lusion.co` 是固定视口系统：首屏深紫底、红色缠结物体、居中白色衬线标题和固定在顶部的导航；滚动后场景以横跨视口的板状区块推进，下一场景从底部进入，白色雕塑头先跨过板缘，蓝色纹样与背后人物投影接着接管。随后巨型 “MAGINATION” 字样在透视中横越前景，人物剪影站在粒子喷溅前。About 页用线框跑者、粒子尾迹与带反射的水面形成纵深，后半段切为黑白。官方说明确认宇航员、门户、反向滚动、点击减速和 About 流体模拟；因此 Vagus 的纵深目标应由真实空间层、遮挡和相机／场景变换实现，不能降级为一张图整体缩放。

以上新证据说明：低干扰背景不等于单色渐变；背景的丰富度来自前中后景之间有明确功能，Lusion 甚至允许场景全屏复杂，只要正文进入独立阅读状态。Vagus 仍须保持一套现代物件、中文可读和自身叙事，不复刻三站的角色、品牌、配色或素材。
