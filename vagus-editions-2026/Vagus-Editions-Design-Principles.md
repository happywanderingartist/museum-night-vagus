# Vagus · Editions 艺术指导

用一个能被迅速读懂的视觉命题组织页面：角色正在做什么、现代物件为何出现在这里、观众接下来能看什么。借鉴 Shopify Winter ’26 的叙事关系与制作方法，形成 Vagus 自己的作品集语言。此文件不是 Shopify 官方设计规范，不授权复制其插画、商标、字体文件或页面。

## 使用边界与资料

用于视觉方案、原始素材提示词、分镜、页面布局及审阅。一般后台、普通表单和无关项目不自动采用。Vagus 的新指令优先于本文件，项目约束不能推广成所有品牌的规则。

开始时读取 [项目约束](#vagus-constraints)；做画面时读取 [场景与绘画语言](#scene-grammar) 和 [分镜](#storyboard)，审阅时使用 [检查表](#checklist)。追溯事实使用 [来源](#sources)，交接或安装使用 [Codex 指南](#codex-guide)。对照 [反面案例](#anti-examples) 检查是否只做了换皮。

## 决策顺序

1. 核验原稿与真实内容。写明已看到的文件、缺失项和本轮可改区域。没有原稿时可以独立探索，但不能称为忠实修改或已恢复原构图。
2. 先定一句视觉命题，再定角色、一个现代物件和视线／动作关系。思想者是近现代雕塑形象，不要称其为文艺复兴作品。
3. 先画黑白布局：主体轮廓、标题、内容入口三种视觉重量。选择全屏、半屏或三分之一结构，再定颜色与材质。
4. 先交无文字原始素材，再用可编辑文字与 UI 叠加成审阅稿。先看静态稿，内容成立后再设计滚动。
5. 用检查表复核，说明通过项、剩余问题与验证范围。结构校验、视觉审阅与浏览器实测分别报告。

## 核心规则

| 决策 | 应形成的结果 | 失败信号 |
|---|---|---|
| 强主视觉 | 一个角色／动作形成第一眼的视觉锚点，缩小到约四分之一仍能辨认 | 场景、道具、标题与卡片同时抢视线 |
| 适度不对称 | 主体偏一侧，以文字、留白与视线平衡；重要元素仍落在清晰对齐线上 | 任意旋转、散落小标签、刻意倾斜 |
| 精准反差 | 古典角色与一个有叙事作用的现代物件发生可信互动 | 多个设备堆出“AI 感”，物件只是摆设 |
| 字与主体融合 | 标题尺度、轮廓、基线与主体共同构图；必要时有少量局部遮挡 | 默认标题在左、图片在右却没有任何呼应；为融合而遮住关键词 |
| 低干扰背景 | 有前中远景、光线方向与绘画材质，文字区使用低对比色块；细节密度从主体向背景递减 | 把低干扰误解成纯色底加抠图；或宫殿、光束、纹理和霓虹同时抢戏 |
| 灵活布局 | 以内容决定主视觉占满屏、占半屏或约三分之一；比例指宽度，停留高度另定 | 三种比例变成固定轮播模板；所有页面同一颜色 |
| 快速转场 | 短过渡后给作品稳定阅读时间；用户可立即继续滚动 | 滚很多屏只播一个镜头，文字随时间消失 |
| 作品可读 | 标题、入口和真实作品优先，作品有可进入的独立阅读状态 | 大场景淹没作品，用假缩略图或虚构数量补齐布局 |
| 素材／UI 分离 | 原图无标题、导航、按钮、气泡；背景、主体和 UI 可分别调整 | 一张完成图承担网站，移动文字必须重画人物 |

这里的“一个物件”、比例、速度和数值预算是本技能的迁移规则，并非已证实的 Shopify 全站规律。强主视觉不等于每页都铺满三维场景；融合也不要求每个标题都被遮挡。

## 本轮 Vagus 约束

使用冷色、有空间层次但信息克制的绘画场景与竖向文字入口；保留“AI行业观察”。首屏元素上移、简介缩小且自然连续排版。不要黄色系、透明卡片、卡片缩略图、额外说明和底部注释；暂不加入复盘与经验。“查看全部作品”作为普通文字链接。未核实的“10+”不出现。

思想者保持沉思姿态与一台无品牌笔记本的明确关系；默认删除旧稿中的悬浮屏、气泡和古典大厅。人物应真实坐落于环境，与背景共用地平线、接触阴影和光线；不能用孤立产品棚拍抠图代替完整艺术指导。当前已看到的是两张思想者合成稿，不等于已拥有整站首屏或可编辑源文件。

## 交付合同

每轮交付包含：一句视觉命题、构图与尺寸、无字素材、独立 UI、成图预览、分镜、来源与验证状态。用户只要分析或提示词时只交该层级。完成图只能叫视觉方案；没有页面与操作证据，不称为上线、可交互或已完成浏览器验证。

## 思想者页面

本轮命题：一个习惯长久思考的人，遇到一台即时回应的电脑。幽默来自角色习惯与现代工具的时间反差，不依赖聊天气泡解释笑点。

主体偏右、左侧文字和入口竖排；完整保留头、托腮的手、电脑关系与底座落地感。人物可在大标题外轮廓附近形成呼应，标题与脸、手、电脑不得相互淹没。默认一台无品牌笔记本，不加手机、耳机、透明屏、代码雨、芯片、发光脑或机器人。背景不出现古典大厅、柱廊、金色窗光；使用冷色的前中远景、材质与统一光线承托。用户已否定第一版纯紫色背景的单调感，因此不能继续把“背景简单”执行成没有场景。

本轮建议的 1600×900 坐标是新构图提案：安全边距 64px，顶栏约 72px；标题在 y≈110–240；竖排入口在 x≈64–680、y≈400–640；主体约 x≈780–1510、y≈180–880。制作后根据真实透明边界微调，不把这些数值包装成原图测量或 Shopify 参数。

## 不确定项的处理

独立整站首页未提供，所以本约束仅覆盖已恢复思想者首屏及公共结构。生成新稿可继续，忠实修改其他首页须先拿到该页。作品内容先保留已出现的三个标题；不虚构发布日期、成绩、经历、产品指标或新作品。对“上移”的歧义只执行可见顶栏整理，不假装完全还原批注。

# 设计检查表

先用约 400px 宽缩略图检查主次，再以目标尺寸检查文字、边缘和操作。数值是 Vagus 的试制起点，视觉判断与真实测试优先。

## 素材与构图

- [ ] 已打开正确原图；列出原稿、参考图、编辑目标各自角色。
- [ ] 能用一句话说清角色与现代物件的关系；只有一个承担笑点的现代物件。
- [ ] 缩略图首先看见主体或标题形成的主视觉，而非背景装饰。
- [ ] 主体偏心但有对齐线、留白与视线平衡；不是随意散落。
- [ ] 头、双手、电脑的数量、接触、透视与遮挡可信；底座不悬空。
- [ ] 背景细节明显低于主体；去掉背景后视觉命题仍成立。
- [ ] 背景具有可读的空间、光线或绘画层次；不是纯色底加人物贴纸。前景落地、远景柔化、文字区安静同时成立。
- [ ] 视觉参考已实际看图；若只读到网页正文或图片描述，明确标注证据不足，不自称已体验原站视觉。
- [ ] 标题与主体轮廓、基线或局部遮挡有明确关系，关键词完整可读。
- [ ] 无黄色系主调、金色大厅、霓虹屏幕、装饰科技元素。

## 文字与内容

- [ ] “AI行业观察”文案准确；简介为一个自然段，不强行拆成短句。
- [ ] 入口竖排，仅标题／序号／必要箭头；无图片卡、透明卡与多余说明。
- [ ] “查看全部作品”是文字链接，没有凭空添加作品数量。
- [ ] 暂无复盘、经验与底部注释；导航和作品目的地状态如实标记。
- [ ] 展示真实作品时，截图比例、标题和链接可辨，不被视觉特效遮挡。
- [ ] 正文起点 16px、辅助文字起点 14px；这是本轮建议，不以用户“再小一点”为由无限缩小。
- [ ] 实现时验证普通文字对比度至少 4.5:1，大字至少 3:1；界面必要边界与焦点同样检查。

## 分镜与实现

- [ ] 已分别指定画面宽度比例和页面停留高度，不把半屏误当半屏高度。
- [ ] 作品有稳定阅读段；过渡起点、终点与反向滚动状态明确。
- [ ] 首屏立即有内容，过渡起点建议 180–360ms；随滚动过渡建议 0.25–0.6 个视口，不是网站原始参数。
- [ ] 没有为一个镜头强制占用多屏；无需等待动画才可点击或继续滚动。
- [ ] 减少动态效果时取消位移、视差和固定长镜头，保留静态作品及内容顺序。
- [ ] 无 WebGL／素材加载失败时仍可读；静态降级可抵达全部内容。
- [ ] 原始素材没有烧入导航、按钮、标题、卡片、聊天气泡或水印。
- [ ] 背景、主体、UI 独立；PNG 声称透明前检查真实 alpha，不以棋盘格图案充当透明。
- [ ] UI 文字可编辑；视觉稿、可运行页面和上线状态分别标注。

## 评审结论

命题／构图／文字／分层／节奏分别给出通过或具体修正点。任一真实内容被遮挡、虚构或无法抵达时不通过；手部穿模、额外物件、背景抢戏应在最终交付前处理。格式验证通过不代表审美已获用户接受；没有浏览器操作证据不报告动效、响应式或键盘访问通过。

# 场景与绘画语言

## 核心修正

“低干扰”描述细节与对比的分布，不描述背景是否为空。纯色底加独立石像虽易读，却缺少用户要求的绘画世界、空间关系和叙事气氛，不能仅凭古典人物与电脑就宣称达到 Shopify Editions Winter ’26 的视觉方向。

采用三层空间：前景提供落地与尺度，中景承托角色动作，远景建立空气与时间感。一个例子是冷灰石台／露台、沉思角色与笔记本、低对比远山和宽阔云层。不是要求所有页面使用山、树或云；每层都要能说明它对角色／内容的作用。

## 画面配方

| 层 | 要解决的问题 | 具体做法 |
|---|---|---|
| 主体与道具 | 画面讲什么 | 角色姿态和一个现代物件是高细节区；材质与动作可信 |
| 前景 | 主体在哪里、尺度多大 | 接地平面、局部石台、同方向接触阴影；避免悬浮贴纸感 |
| 中景 | 如何把视线引向主体 | 一条缓慢的地面斜线或一个大色块转折，不堆小道具 |
| 远景 | 空间与气氛 | 少量大体块、空气透视、绘画色层；远处比主体柔和 |
| 文图区 | 如何阅读 | 文字后方有低对比、少边缘的区域，但颜色仍属于同一环境 |
| 字体 | 是否属于这幅画 | 字号、宽窄、字重、明暗与画面整体设计；中文不能机械套用英文花体 |

画面既要有“可以进入的地方”，也要有“可以读字的安静区域”。真实的空间关系比额外加纹理更重要。不要用全屏透明蒙版把场景压成灰雾，也不要通过把主体缩小来腾出所有文字空间。

## 参考分析的证据门槛

读到官网正文与制作技术，不等于看过官网画面。视觉分析前应实际看至少一张相关首屏和两张内容场景的截图或录屏；若实时浏览失败，可使用带原始链接的公开截图，但明确它是转载证据。仅取得图片搜索的描述时，不能称为像素级审阅，也不能声称完成动效体验。

迁移应提取构图、明暗组织、媒介质感和现代物件的叙事作用，而不是复制角色、道具或整幅画。Shopify 原站有不同场景与多个现代物件；Vagus 的“一台电脑”是减少本页信息竞争的项目选择，不是原站统一定律。

## 静态验收

先关闭 UI 看场景：主体、地面、环境是否形成一个世界；再打开 UI 看作品入口是否仍第一时间可读。将背景缩到 25% 时应该看到少量有层次的大色块，而不是密集边缘；完整尺寸下应有可感知的材质与光线。只通过其中一项的稿件仍需修改。

# 分镜与构图指南

以下是本轮 Vagus 的迁移方案，不是对 Shopify 原站镜头逐帧复刻。先做可读的静态帧，再决定动画。

## 布局语法

| 类型 | 适合的内容 | 画面组织 | 阅读保护 |
|---|---|---|---|
| 全屏 | 开场或章节主题 | 主视觉场景贯穿画布，文字有独立安全区 | 不是全屏视频封面；导航与内容入口立即可见 |
| 半屏 | 主题与内容同等重要 | 约 50:50 或轻微偏置，允许主体越过虚拟分界 | 内容有稳定背景，文字不穿过人物脸和手 |
| 三分之一 | 阅读、列表或单件作品介绍 | 主视觉约占宽度 1/3，其余交给内容；左右可换 | 不是强行三列，也不是三张卡片 |

比例是主视觉占画面宽度的近似值；页面高度和停留长度取决于内容。只在宽屏母版上定方向，实际变窄时按阅读顺序重排，不能机械缩小整张图。

## 思想者章节分镜

| 帧 | 画面／布局 | 内容状态 | 动作与触发 | 结束／反向状态 |
|---|---|---|---|---|
| 01 建立 | 全屏冷紫蓝舞台；思想者偏右，标题大幅横向展开 | 顶栏、简介和三个竖排入口立即可读 | 初次出现可用很短淡入；不等待角色入场 | 静态也完整，返回顶部恢复同一构图 |
| 02 接近 | 主体收至约半屏，标题与图像建立更紧的轮廓关系 | 入口保持可点击，不随滚动消失 | 在约 0.25–0.6 视口内完成一次裁切／平移 | 用户停滚即停；反向滚动连续恢复 |
| 03 阅读 | 主体占约三分之一，内容区约三分之二 | 展示一件已核实作品的标题、实际内容与进入链接 | 背景和主体稳定，只在进入时短淡入 | 无作品内容时停在方案稿，不造案例 |
| 04 离开 | 下一章节以独立色块或清晰边界出现 | 当前作品可继续访问，目录可跳转 | 180–360ms 为定时过渡试制起点；滚动版短距离衔接 | 无动态偏好时直接切换文档流 |

以上时长和距离是推荐初值，必须在真实页面调整；未实测不能宣称“快速流畅”。避免同时做镜头旋转、文字逐字揭示、卡片横飞和背景变形。

## 图层合同

从底到顶：背景底色／低频光影 → 可选背景文字 → 主体与单个现代物件 → 前景可编辑标题 → 简介／导航／作品入口 → 焦点等交互状态。背景大字若被主体遮挡，前景仍需有完整可读的主题标题。

人物 PNG 可以将笔记本与人体作为一个可信接触关系的素材整体。若后续需要单独移动电脑，应重新制备匹配透视的物件与遮挡层，不能将生成图中的电脑粗切后假装获得完整可编辑三维资产。

## 素材生成示例

Use case: stylized-concept. Asset type: isolated editorial sculpture for a desktop portfolio hero. A pale cool limestone Thinker-like adult sculpture seated on a low integral stone plinth, leaning forward with one hand supporting the chin and the other naturally using exactly one unbranded dark cobalt laptop on the lap. Full head, hands, laptop and feet visible. Three-quarter view, quiet dry humor, convincing anatomy and contact. Cool neutral studio light, detailed stone but no dramatic gold light. True transparent background. One subject, one laptop, no other props, no lettering, no interface, no caption, no logo, no border, no room, no columns, no holograms. Compose the object centrally inside its own asset with enough margin; the UI layout will place it on the right separately.

原始素材提示词里不写页面导航和按钮文案。需要改变场景时保持主体／道具的命题，先调整占幅、裁切和背景重量，不能只换背景名词。

# 反面案例与修正

| 反例 | 为什么失败 | 应形成的画面 |
|---|---|---|
| 金色宫殿换成紫色宫殿，卡片和标题位置不变 | 只换场景，视觉重量与层级没有改变 | 先删除背景竞争元素，重排标题、主体、竖向入口 |
| 纯紫背景＋石像抠图＋大黑体，就称 Shopify 风格 | 保留了道具反差，却丢失空间、绘画媒介和整体编排 | 建立前中远景、共享光线与接地关系，并让文字融入同一视觉世界 |
| 思想者戴耳机、拿手机、膝上电脑、身旁机器人 | 观众要先读懂道具清单，笑点变弱 | 一个笔记本，通过托腮与使用电脑形成关系 |
| 左边均分三卡，右边一个小石像 | UI 模板压过艺术指导 | 大主体与少数文字入口；用尺寸关系而非卡片数量建立秩序 |
| 把“AI行业观察”藏到头和电脑后面 | 融合变成不可读 | 主体靠近标题末端或共用基线，遮挡只发生在非关键留白 |
| 古典宋体、金框、罗马数字直接全套移植 | 复制可识别表皮，Vagus 自己的现代感消失 | 保留叙事反差，换为冷色、现代中文黑体和独立版式 |
| 一张图内画好品牌、导航、气泡和按钮 | 无法修改文案、定位或为不同尺寸重排 | 无字人物原图 + 可编辑 UI + 独立合成预览 |
| 图片里写“透明”，背景其实是棋盘格 | 无 alpha，不能真正叠加 | 检查 alpha 范围和透明像素，展示不同底色预览 |
| 十屏固定镜头，标题两秒后消失 | 阅读被时间控制，访客要做无效滚动 | 短过渡、稳定阅读、可跳转目录 |
| 每页强制同色、同一 50:50 布局 | 作品失去个性，节奏单调 | 公共文字系统保持一致，场景颜色与占幅随内容调整 |
| 为排满三分之一版块编三件作品 | 版式被当成事实来源 | 只有一件就展示一件，缺数据时不造假 |
| 没有旧稿，却说“保持原构图精修完成” | 混淆独立生成与忠实修改 | 标注独立探索；有原图才能核验保留范围 |
| 认为 Shopify 既然用了三维就必须上 WebGL | 技术成本取代视觉目标 | 先静态；只有明确互动收益才增加技术 |

“更现代”应体现在节制、比例、字体、清晰的操作关系和材质上；它不自动意味着玻璃卡片、代码雨或蓝紫霓虹。“背景安静”是降低视觉竞争，不要求纯色到毫无空间感。

# 思想者视觉方案 · 01

命题：一个习惯长久思考的人，遇到一台即时回应的电脑。保留古典角色与现代笔记本的反差，用姿态、尺度和材质传达幽默，删除用来解释笑点的气泡。

本轮选择冷紫蓝平面舞台、浅灰石质人物、深蓝无品牌电脑。与旧稿相比，关键变化是背景退让、标题与人物共同占据上半屏、内容入口从横排卡片改为竖向文字。不是把金色大厅换成另一座大厅。文字用现代中文黑体，Vagus 保留衬线标识，与石质轮廓建立轻微古今反差。
