# Vagus · Editions × Contra 艺术指导

3.4用户修订优先：不能每页都是电脑。保留“一个精准跨时代物件与角色互动”，不把笔记本当固定答案；当前首页保留粉色笔记本、饮品改透明冰美式，思想者试用骨白／炭黑机械打字机。下文与旧参考文件中限定电脑的内容只作为历史样例，不覆盖此要求。标题须与正文有明显字体区别：当前宋体展示标题＋细无衬线正文，避免全页同一细黑。

当前视觉修订必须先读 [章节色彩与谐趣](references/chapter-personality.md)。它覆盖下面旧的“优先B”和冷灰示例：用户要求不同页有独立色调、场景与动作，不能将青绿＋粉色复制到每页，也不能以深色石雕室内等同复古未来主义。

3.3修订：相邻页不能仅交换同一组主辅色。思想者当前采用闭馆阅览室命题，墨绿／骨白／炭黑／少量朱红，不再沿用已否定的粉蓝台阶与圆窗。丰富度来自有叙事作用的前景、工作痕迹和远景空间，不以空墙＋电脑或堆装饰通过验收。

用一句视觉命题统领角色、现代物件、字体与内容。提取组织方法，不复制可识别画面；本文件不是两站官方规范，不授权其图像、字体、品牌或代码。用户后续明确更改要求时，以新要求为准；新旧要求冲突但未明确取舍时，指出冲突再确认，不把旧约束当永久禁令。

先读 [项目约束](references/vagus-constraints.md) 和 [实际视觉研究](references/visual-study.md)。制作读 [构图语法](references/scene-grammar.md)、[分镜](references/storyboard.md)；审阅读 [检查表](references/checklist.md)、[反例](references/anti-examples.md)；查证读 [来源](references/sources.md)，交接读 [调用指南](references/codex-guide.md)。只分析或只写提示词时不自动生成、改站或发布。

## 决策顺序

涉及背景简陋、主视觉质感、人物与环境融合或生成素材时，读取 [背景美术合同](references/background-art-direction.md)。交付一份填好的背景 brief：命题与路线、明暗结构、真实文字区域、光线／材质、人物边缘、拉远终帧、素材需求和验收。几何夹具只验证机制；背景美术未制作或未接受时，不能报告“视觉达到参考”。冷灰墨绿是示例提案，不是用户已选配色或全站固定规范。

用户要求“套用后生成同样效果／接近参考站”时，进入**效果重建模式**：读 [素材合同](references/asset-contract.md) 与 [效果配方及接入](references/effect-recipes.md)，先输出目标效果矩阵，再用包内可执行参考校验机制。静态气质、运动机制和最终视觉相似度分别验收；不得以轻微缩小＋淡出替代用户点名的近景拉开、图层差速、字图交接和正文接管。所需素材不足时列制备任务，不静默降低目标，也不承诺只靠 Skill 保证一模一样。允许使用自己的图像、色调和材质，不能直接复制参考站资产。

3.0 的沉浸式效果配方优先于 2.1 合同的“首版不驻留”与轻淡出方案；旧合同仅用于用户明确选择轻量编辑页的情形。不要把 A/B 两条路线、3D 与 2.5D、实测与重建初值混称为同一种效果。用户只要求完善 Skill 时，更新规则／参考资源并验证，不擅自重建正式网站。

涉及网站、动效、转场或滚动交接时，额外读取 [动效研究](references/motion-study.md) 与 [网站动效合同](references/motion-contract.md)。交付每段的驱动、触发、图层端值、阅读终点、中断／反向、导航和降级；不能只给静态图或“快速流畅”形容词。现有 animation-vocabulary 用于效果命名，animate 用于实际制作，review-animations 用于已有实现审阅；不因列出这些技能而宣称已安装新库或完成网站。缺少其他技能时按本包合同继续，不依赖本机绝对路径。

1. 打开正确原稿，区分原稿、参考、素材与缺失内容。截图不证明已有整站代码和功能。
2. 写一句视觉命题，确定第一眼看什么、第二眼读什么、下一步点哪里。
3. 先选构图路线，再做黑白视觉重量稿，最后定颜色与媒介。不能先抠人物再找背景填空。
4. 图像与 UI 分离交付，但作为一个画面设计；图层分离不等于艺术指导分离。
5. 静态可读后才设计滚动；分别报告结构校验、视觉审阅、行为实测和用户接受。

## 两条路线

**A 沉浸式绘画章节（Shopify 借鉴）**：图像覆盖场景，动作、光线、环境与现代物件构成一个世界；巨字可跨人物轮廓，章节索引提供位置感。适合主题开场，不要求每页都是风景或冷色。

**B 编辑式裁切（Contra 借鉴）**：安静底面、巨大局部人物、编辑式字体层级与一种受控媒介处理相互配重。以裁切、尺度、边界处理和留白产生张力。大面积素底可以成立，不必补自然景物。网点是参考的一种手法，不是必须复制的标志。

全屏、半屏、三分之一指主图近似占宽，可分别服务不同内容；不是必须把同一个人逐次缩小的滚动模板。

## 可迁移规则

| 规则 | 做法 | 失败信号 |
|---|---|---|
| 强主视觉 | 动作或字图组合形成缩略图也明确的视觉锚点 | 小石像旁堆装饰卡片 |
| 适度不对称 | 偏心与越界受网格、明暗、留白配重控制 | 随意散落和旋转 |
| 精准反差 | Vagus 用一个现代物件与古典角色互动 | 设备清单、气泡解释笑点 |
| 字图融合 | 尺度、轮廓、基线共同构图，遮挡可选 | 挡关键字、脸和操作 |
| 低干扰 | 控制文字区边缘与对比，复杂度服从阅读 | 必须纯色；必须远山；全屏灰蒙版 |
| 灵活章节 | 随内容改变占幅与色调，公共导航有秩序 | 全站同色同模板 |
| 快速转场 | 短过渡后有稳定阅读，可跳转及反向恢复 | 多屏等待、计时隐藏正文 |
| 作品可读 | 真实内容有独立完整阅读状态与入口 | 假案例、虚构数量填版 |
| 素材／UI 分离 | 无字图像、可编辑 UI、独立预览 | 导航按钮烧入生成图 |

“一个现代物件”、非黄色、竖排文字是 Vagus 约束，不是两站全局规律。参考实图允许暖色、多物件、复杂画面、卡片与大胆人物裁切。思想者不是文艺复兴作品。

## Vagus 当前落点

保留“AI行业观察”；品牌导航置顶；简介缩小、连续自然段；三项入口竖向文字排列。“查看全部作品”用普通文字链接，不显示未核实“10+”。不加图片卡、透明卡、多余说明、底部注释、复盘或经验。现代而非科技感，不用黄色主调、金色大厅、悬浮屏和代码雨。

思想者默认一台无品牌电脑，托腮与电脑关系明确。优先探索 B：放大偏右主体，允许有目的裁去下身／底座，保留头、关键手势与电脑；以统一媒介和构图解决单调，不在棚拍石像后拼自然景观。若选 A，统一重做光线、透视和绘画材质，而非只换背景。两版旧方案均被否定，不作为通过范例。
