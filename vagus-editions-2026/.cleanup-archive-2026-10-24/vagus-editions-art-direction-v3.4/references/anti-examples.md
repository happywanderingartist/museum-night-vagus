# 反面案例

背景专项：冷灰墨绿只能定义配色，不能证明美术成立；整屏颗粒不能代替色阶和视线组织；几何机制夹具不能作为背景已完成的范例。具体正向制作与验收合同见 background-art-direction.md。

| 反例 | 问题 | 修正 |
|---|---|---|
| 紫底太空，后面补远山 | 背景名词替代构图，媒介不一致 | 选 A 或 B，重排重量与光线／材质 |
| 所有画面必须前中远景 | 一种空间配方冒充艺术规律 | 编辑底面靠裁切与边界也成立 |
| 必须完整露脚 | 限制主体尺度和张力 | 保留叙事动作，允许有目的越界 |
| 复制 Contra 女性、网点键盘、青绿 | 照搬可识别表皮和资产 | 提取时代反差和媒介统一机制 |
| 宫殿换成紫色，卡片原封不动 | 换皮未改层级 | 删除竞争信息，重排主视觉与入口 |
| 电脑、手机、耳机、机器人齐上 | 笑点稀释 | Vagus 只留一个电脑关系 |
| 大字挡住关键标题 | 融合损害阅读 | 用基线、轮廓、尺度，不必遮挡 |
| Contra 有卡片就给 Vagus 加卡片 | 参考覆盖用户要求 | 研究记录事实，本页仍竖排文字 |
| Shopify 暖色就恢复金色大厅 | 无视项目非黄色限制 | 借章节变化，不照搬被禁色调 |
| 看截图声称所有动画已体验 | 证据越级 | 分开截图、导航、自述与未测指标 |
| 在原图生成导航按钮 | 修改与响应需要重画 | 无字图像＋可编辑 UI |
| 为填版编作品与“10+” | 设计变成事实来源 | 缺内容就停在方案 |
| 用很多三维技术证明像参考 | 成本代替设计 | 静态先成立，再为收益加技术 |
