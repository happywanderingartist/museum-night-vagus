# 网站动效研究：Shopify × Contra

核查 2026-10-23；配合 visual-study.md 阅读。证据分级：O 为本轮浏览器观察；S 为制作方自述；I 为合理推断；P 为 Vagus 提案；U 为未验证。不要把几种等级揉成“已实测全站”。

## Shopify：一段视觉叙事，不是一张背景图

| 环节 | 拆解 | 证据与边界 |
|---|---|---|
| 首屏入场 | 制作者称 CSS／SVG 承担开场，线条绘制与标题变换独立于重三维加载 | S；未捕获完整冷启动，不报毫秒或重播规则 |
| 场景系统 | 每幅绘画是独立 R3F 场景；时间轴供设计师调整多个属性 | S；时间轴不等于自动播放，也不证明每处都是视差 |
| 首屏到章节 | 中央主题／目录在章节状态变为左侧定位系统，顶部导航维持屏幕位置感 | O：截图有前后状态；中途路径与插值未连续记录 |
| Sidekick 章节内部 | 巨字状态推进后，人物取景更完整，说明文字和视频入口出现，底部撕纸状边界进入；再推进出现浅色正文底和黑色导航 | O：首、中、后状态；人物取景变化原因可能是相机／对象变换或组合，具体实现为 U |
| 图像到阅读 | 场景让出阅读空间，正文不全压在画上；目录随明暗场景改变可读对比 | O；不能推定使用 mix-blend-mode 或某个 CSS 实现 |
| 悬停小动效 | 制作者称部分 Rive 效果先用首帧封面，悬停才播放；线性动画有视频导出优化 | S；本轮未完成逐控件悬停，具体触发与复播 U |
| 性能降级 | 制作者说明多档质量、静态图与 CSS 后备 | S；本机未强制验证所有档位，不引用自报帧率作本机性能 |

本轮真实操作：首屏、向下导航、Sidekick 锚点，以及从 Sidekick 两次受控 PageDown 的终态截图。首次对 body 发 PageDown 跨至 Marketing／Product Network；之后聚焦目录再发 PageDown 得到分段状态。前者不能当作一视口距离，原因未确证。DOM 观测到一个约覆盖视口的 canvas；canvas 自身 computed position 为 static，因此不据此断言它自身 fixed，可能由祖先定位。

从浅底正文 PageUp 返回后，恢复了人物、说明文字、视频入口与撕纸边界的组合，验证该段可反向返回而非一次性消失；仅验证终态恢复，未测逐帧可逆或精确相机轨迹。

## Contra：预加载、内容推进和局部互动应分开看

| 环节 | 拆解 | 证据与边界 |
|---|---|---|
| 预加载接首屏 | 制作者说明各页独立预加载衔接主视觉，首页以女性使用网点电脑建立主题 | S；本轮到达时已是完成态，未逐帧看到加载过程 |
| 首屏到生态 | Edge 首屏向下推进，绘画主体退出可见区，青绿生态标题与模块进入，顶导航仍可见；聚焦导航有清楚焦点框 | O：离散状态；不能凭此认定背景有连续颜色插值 |
| 模块与后续拼贴 | 生态模块、人物局部、留白拼贴和统计块形成不同阅读密度 | O：本轮与前次截图；每块 reveal／parallax 的具体区间 U |
| 滚动机制 | 制作者明确有滚动关联效果与自定义代码 | S；Framer 的 appear、scroll trigger、scroll transform 不是同义，不能只因 Framer 就假定内部机制 |
| 按钮文字 | DOM 中可见多份同文案节点，可能服务文字滚动／替换效果 | I；重复 DOM 不证明实际悬停或键盘行为已通过 |
| 页面跳转 | 有独立 research／jobs 链接 | O：链接结构；离场和下一页入场的时长、是否共享元素 U |

Chrome 本轮 Contra 出现空白；已按授权改用 Edge，正常呈现与滚动。空白不被解释成预加载设计，也不认定站点永久故障。

## 判断驱动的方法

先记录输入与画面状态。滚动小步 → 停止 → 原地等待 → 反向 → 直接锚点进入。随位置回溯的是 scroll-linked 候选；进区后停滚仍自行结束的是 triggered/time 候选；原地持续周期变化是 idle 候选。一段可能混用。两个终态截图不能证明相机路径、缓动、精确速度、FPS 或循环周期；无法连续取样就标 U，研究仍可输出 S 与 P，不冒称复刻。

记录原始时间、输入方式、实际滚动位置、视口、页面／章节、静止对照与截图路径；工具等待时间不是动画时长。CSS／WAAPI 元数据不能覆盖 canvas 内部动画。仅当工具允许且确实取得数据时报告测量值，不能为补证据绕过控制入口。
