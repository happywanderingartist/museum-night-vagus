# 人物动作第三批：实施范围

2026-10-27。保留首页眨眼和思想者 5 秒滑动 / 2 秒停顿；手机固定、背面朝观众。新增 START 递票、运营编辑校正红封面、播客侧头倾听、文艺后台抬对讲机、视觉创作递画笔、关于页递名片。每个动作作用于原画局部，手和所持物保持相同刚性变换；区域边缘与肩腕通过连续网格过渡。无需上传素材、付费生成或新 GPU 依赖。

## 开源项目审阅

范围：GitHub pixijs/pixijs，官方 README、tests 目录、MIT 许可证及 Releases。2026-10-27 页面显示约 48.6k 星；v8.22.0 于 2026-10-01 发布，维护者 Zyie，包含可访问性与纹理更新修复。星标只作规模线索。官方用法是 Application.init、Assets.load、Sprite、ticker；仓库包含测试与示例。https://github.com/pixijs/pixijs https://github.com/pixijs/pixijs/releases

可复用优点：共享纹理、锚点一致、局部网格和集中生命周期，适合手与道具保持接触。局限：渲染器不会补全被遮挡的肢体或画面，增加 GPU 运行时也不能直接获得真实三维。此次借鉴组织方式，沿用已有 SVG 网格，不复制库代码或引入整库。

## 验收边界

检查所有变形边界固定、物件直线不被拉弯、动作回到原位、离屏和减少动态停止、模块实际通过本地 HTTP 提供。原画 SVG 合成检查用于发现接缝，不能替代浏览器播放。Chrome 被自动审批拒绝，禁止换入口绕过，浏览器视觉与性能验收仍待完成。3D 本轮只提交资产与制作计划。
