# 思想者 · 免费动效试稿

这是独立的局部动作试稿，不覆盖 prototype-v1，也不是全站最终版。Blender 4.5.15 LTS 和 Three.js 0.186.1 已在本机运行，无付费 API、无云端生成、无素材上传。

R3：已同步修正固定背壳视角，不露屏幕，整段指腹不穿过玻璃。手机/手部背后使用内置图像编辑制备的局部干净补图，只应用小范围蒙版，故上段“无云端生成”仅是初版历史。原画和手部像素仍保留；主站site-v2/REVISION-R3.md有当前32/28项检查、五帧近景和真实循环录制说明。

R2修正：指尖由实际手机玻璃坐标约束，不再独自在空中移动；标题恢复单行AI行业观察，三条作品入口下方恢复查看全部作品。接触、上划、停顿和支撑位置有独立检查，初版时序通过并不代表接触曾通过。手部仍是原画2.5D，不以全三维人物名义交付。

## 打开

双击本目录 `start.cmd`，保留终端窗口，在 Google Chrome 打开 **http://127.0.0.1:4178**。已有该端口的预览正在运行时，直接使用现有地址，不重复启动。终端中 Ctrl+C 停止服务。不要用 file:// 打开：浏览器的模块和模型加载需要 HTTP。服务器只监听本机，不是公网发布。

便携包已包含网页、模型、原画副本、Three.js 必要模块及 MIT 许可证。只需现有 Node.js，无需登录、联网、npm install 或 Blender 就能播放。Blender 只在重建资产时需要。

## 检查动作

2026-10-25最新修改：手机在任何时刻都不转动，包括首次进入、复访与检查模式；只有手指在固定屏幕上滑动，每7秒一轮，滑动5秒、停2秒。下拉菜单可以检查0、1、2.6、5.5、8秒关键帧，它是显式审阅模式，会显示“逐帧检查”，不是实时播放的性能证据。选回“正常播放”继续循环。右下角的计时读数来自实际绘制帧。

暂停按钮、进入阅读区、切换标签页和系统减少动态设置都会停止自动推进。离开后返回不追赶时间。WebGL不可用或加载失败时保留原画和HTML作品入口。新的连续网站和START/Hug独立页在同级site-v2，端口4179；本目录仍用于单独检查思想者动作。

## 画面边界

手机是真实三维模型；网页手部是原画像素贴在可变形的独立2.5D曲面上，面部、主体和房间仍是绘画。旧手机/手附近用原图邻近区域进行局部背景重建，主原图文件未修改。这里的遮罩、接触与空间融合仍属试稿，不等同于完整人物雕刻或原作无损分层。三维手部代理也在模型中，但造型未达原画水平，网页默认隐藏。

`assets/gesture.blend` 可在已配置的 Blender 中编辑，`assets/gesture.glb` 是网页资产；`assets/gesture-review.png` 是代理资产检查图，不是网页最终截图。作品三条标题来自已有原型，正文及真实外链仍待接入。

## 开发与复现

```bat
node --test tests/*.test.mjs
node server.cjs
```

仅需重新准备厂商模块时：`npm ci --ignore-scripts --no-audit --no-fund`，然后 `npm run prepare:local`。该准备脚本从原项目复制原图，故独立解压包里不需要也不应运行它。重新制作模型时，在原项目结构下运行 `scripts\build.cmd`；Blender位于同级 `../toolchain/blender-4.5.15-windows-x64/`。解压到其他目录时需相应调整构建脚本中的工具位置。所有工具、缓存和输出均在D盘。

测试详情见 VALIDATION.md，来源和许可见 SOURCE-REVIEW.md。本包不含Blender程序本体、npm缓存、node_modules、账户凭据或其他项目资料。
