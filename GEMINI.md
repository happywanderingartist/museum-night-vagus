# Vagus website project rules

This repository contains the Vagus personal portfolio website and its design work. It also contains case studies for START and HUG; it is not the source repository for those products themselves.

Read [`GEMINI_HANDOFF.md`](GEMINI_HANDOFF.md) before making changes. The current website baseline is `vagus-editions-2026/site-v4/`. The older `vagus-editions-2026/SITE-CURRENT.md` still describes an October 27 `site-v3` state and is stale. Treat dated validation records as historical evidence, not current verification.

The user prefers a continuous inward gallery with a natural vertical reading direction and has rejected horizontal page transitions. The November 9 short-threshold transition is a production proposal, not visual approval; keep it isolated until the user accepts its look. The standalone spatial previews do not replace or automatically merge into `site-v4`.

Prioritize readable content and efficient reading over compressing the page for mobile. Preserve natural Chinese paragraphs, direct navigation, reduced-motion and static fallbacks. Use Google Chrome for browser acceptance; do not silently switch browsers.

Keep project claims tied to evidence. Do not invent personal work, responsibilities, product behavior, user outcomes, clinical effects, or review status. Clearly label proposals, synthetic examples, and unverified work. The START/HUG case pages remain review material until the user approves their content and presentation.

Before website engineering work, search mature GitHub projects with similar behavior and record one reusable advantage and one limitation. Review the current source and its license/tests/actual use before adopting anything; do not copy unseen code or treat stars as proof of quality. Use the project's existing validation for the changed area and state exactly what was checked. Do not claim a prototype check proves production quality.

The root repository has no `LICENSE`; do not add one without the user's choice. Keep ignored private recovery files and local third-party reference reconstructions out of Git. Repository visibility does not publish the website; do not deploy the site unless asked.
