# Vagus Museum Night

Design, prototype, and 3D experiments for the Vagus personal portfolio website.

The main working material is under `vagus-editions-2026/`. Local Blender binaries and large third-party 3D source packages are excluded from Git and remain available only on the working machine.

## Gemini handoff

Start with [`GEMINI.md`](GEMINI.md) for project rules, [`GEMINI_HANDOFF.md`](GEMINI_HANDOFF.md) for the current status and first prompt, and [`GEMINI_FEEDBACK_AND_REFERENCES.md`](GEMINI_FEEDBACK_AND_REFERENCES.md) for recurring feedback, follow-up plans, review branches, and reference sites. See [`GEMINI_SKILL_MAP.md`](GEMINI_SKILL_MAP.md) for the seven Skills and four example links, and [`GEMINI_COPY_SOURCEBOOK.md`](GEMINI_COPY_SOURCEBOOK.md) for the public-safe résumé facts and [`GEMINI_SOURCE_MATERIALS.md`](GEMINI_SOURCE_MATERIALS.md) for the redacted Markdown sources and QA JSON reports. The redacted Word/PDF exports are indexed in [GEMINI_RESUME_EXPORTS.md](GEMINI_RESUME_EXPORTS.md); raw unredacted files and QA screenshots/scripts remain local. The active website baseline is `vagus-editions-2026/site-v4/`; isolated spatial previews are experiments and are not automatically part of the site.
